# 凯撒销售移动工作台

独立的手机端业务原型，面向一线销售顾问。保留绿灰色系，以紧凑列表、清晰状态和手机触控规范服务员工办公；延续 commerce-agents 的对话卡片、行程时间线、方案对比及开单核对交互，承接凯撒销售业务职责。

当前目录：`caesar-system/caesar-sales-mobile/`。

## 打开

直接用浏览器打开 `index.html`，或在本目录运行：

```sh
npm start
```

访问 http://localhost:4178 。仅需 Node.js，无需安装依赖。需要改端口时运行 `PORT=4180 npm start`。服务只监听本机。

## 可以演示的流程

- 工作台：今天待办、继续方案、开单草稿、本人进展。
- 客户：搜索与筛选、接待新客、创建与编辑本次需求、沟通记录。同一客户可有不同出行需求。
- AI助手：选客户需求、需求缺项提示、日本亲子6日方案、轻松版调整、历史版本、产品推荐。聊天与方案按需求保存。
- 方案：每日行程、采用产品组报价、记录客户确认、客户版预览及复制、核对开单。
- 产品：关键词、类型、出发地组合筛选及价格／日期排序、日期余位、成人和儿童规格、金额计算、保存及恢复草稿、提交订单。即时确认与二次确认分开。
- 产品分享：介绍或具体报价、指定客户、有效期、复制链接和客户版预览；客户提交咨询，销售核对后接待为出行意向，也可停止分享。
- 订单：收款认领及退回补充、游客资料编辑、合同核对与发起签署、已签署样例、只读资源进度、改期和退订申请、AI解释卡点和回复草稿。
- 订单详情无Tab，“本单办理”直接进入收款与认款、合同、游客资料、出行资料及售后独立页；合同支持附件预览，认款退回在原申请补充并保留记录。
- 头像“林悦”：原型说明、AI不可用及过期报价场景、重置本项目演示数据。

## 演示边界

- 固定业务演示日为 **2026-09-27**。姓名、电话、证件、报价、库存和订单均为样例，不应输入真实敏感资料。
- 本地规则演示AI，没有接入真实模型或 commerce-agents 后端。日本亲子6日是深度场景；不支持的自然语言要求会说明范围，并提供人工编辑入口。
- 采用报价只是引用产品组的演示回复，销售没有资源确认权限。改变日期、人数或方案后须匹配新报价；不套用原确认记录。
- 定制提交进入“待确认”，表示待单团项目审核；标准产品依团期确认方式进入已确认或待确认。
- 认款提交保持“待复核”，不会增加实收；合同发起保持“待签署”；售后申请保持“待审核”，不扣减原订单、实收或自动退款。
- 浏览器本地存储只用于本项目草稿与演示记录；附件只记文件名，不上传文件内容。客户版可以在页面预览或复制文字，由销售自行发送。
- 无真实短信、微信发送、合同签署、银行支付、权限系统、ERP接口或跨项目自动回写。
- 产品分享链接只在同一浏览器、同一预览来源内演示；跨设备访问需要正式服务。指定客户验证码123456仅为演示，不是生产鉴权。有效期默认7天可修改，只是样例条件。

```sh

```

当前UI已按领队移动端三个页面统一规范（2026-09-28），采用一级页底栏、二级页独立返回、分组紧凑列表和AI方案卡片。详细路径和验收证据见 `docs/实施与验收.md`；设计范围见 `docs/设计方案.md`。

## 目录

- `index.html`：独立入口，可直接打开。
- `assets/style.css`：移动视觉及响应式样式。
- `assets/*.svg`：本项目本地旅行插画及图标，无外部资源加载。
- `src/model.js`：样例和业务规则，可独立测试。
- `src/app.js`：页面、导航与演示交互。
- `src/share-model.js`、`src/share-ui.js`：产品分享、客户咨询及接待原型。
- `src/order-ui.js`：订单概览及独立办理页面。
- `server.cjs`：无依赖的本地预览服务。
- `tests/`：金额、状态和异常校验。

UI参考及许可见 `THIRD_PARTY_NOTICES.md`。作为 caesar-system 的子目录独立运行，不依赖后台或 commerce-agents 的服务。
