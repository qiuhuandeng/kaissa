### 1. 需求状态的含义

- **明确提出**：原文表达了需要的业务能力，尚不代表当前系统已经实现或财务政策已批准。
- **会议倾向**：原文使用倾向、建议、参照等表述，保留方向，不替代决策。
- **待确认**：原文未定、跨附件冲突，或缺少足以执行的条件。
- **后续考虑**：原文明示放到后续版本，不据此承诺时间。
- **整理建议**：为了说明角色分工、业务承接或验收方式补充的建议，与附件原文分开表述。

下文需求表没有另写状态的，均为“明确提出”。带有“待确认”“会议倾向”等标记的部分不得直接作为确定规则实施。

### 2. 业务用语

“签约公司”指集团内与供应商签署协议的具体公司；不能用集团统一建档代替各公司的合同和付款责任。“账期”指按协议约定，从出票、回团等起算事件到应付款日的时间规则。“预付”指业务结算前已经付给供应商、以后需要抵扣或退回的款项。“应收、应付”分别指按业务依据应向客户等收取、应向供应商等支付的金额，均不等于钱已收付。“分润”指按约定分配给门店等参与方的收益，计算和支付条件需另行确认。

附件中的ERP在本文写为“业务系统”；AI指人工智能辅助识别；OCR指图片文字识别；OTA指线上旅游平台；POS指银行卡收款终端；SWIFT Code指国际银行识别代码。致远指附件提出的审批系统，12301指附件提出的旅游合同相关对接平台，二者是否具备现成接入条件本次未验证。

## 二、全业务链路与角色任务

五份附件不是五套互不相干的系统需求。共同主线是：供应商及协议准入 → 产品资料与价格规则 → 团期、出行日期及资源名额 → 销售意向与订单 → 合同、收款及订单变更 → 出行执行 → 成本、对账、付款与结算 → 经营统计。

以下是依据会议材料整理的角色分工，不是新增组织制度。

| 角色 | 上游从哪里来 | 最高频任务及主要处理内容 | 处理结果与下游 |
|---|---|---|---|
| 采购、供应商管理人员 | 拟合作供应商及各公司合作需求 | 建档、准入、协议签订、续签、资料及适用公司维护 | 有效供应商与协议供产品、计调及财务使用 |
| 产品经理、产品运营 | 供应商、行程资料、产品方案 | 维护产品、行程、素材、报价规则及销售范围 | 可建立团期或出行日期、可供销售选择的产品 |
| 计调、团控、交通采购 | 产品、资源采购、订单及游客要求 | 维护团期和名额、采购分配、供应确认、执行安排与成本 | 可履约的资源与名单、可核对的成本及结算资料 |
| 直营销售、呼叫中心 | 官网、小程序、电话线索及历史客户 | 分配意向、报价、占位下单、签约、认款、售后发起 | 订单及游客要求交计调；收款和退转款交财务复核 |
| 加盟合伙人、店长、店员 | 总部或分公司授权的产品和规则 | 分级售卖、折扣审批、订单签约、收益查询 | 合规成交订单及可核对的门店收益 |
| 供应商 | 准入协议、产品资料及待确认订单 | 提交产品、确认资源和订单、确认对账结果 | 有效供应确认及双方认可的结算依据 |
| 财务 | 收款流水、成本、协议账期及业务结算资料 | 认款复核、退款转款审核、应付付款、预付抵扣、结算核对 | 可追溯的实际收付和结算结果 |
| 法务、审批人员 | 准入、协议、折扣及特殊事项申请 | 审核资料、权限范围内审批、确认合同适用要求 | 审批结果回到发起事项，业务据此继续 |

不同供应商不能套用完全相同的资料要求；不同销售组织不能统一按普通门店处理；销售价格、供应商结算价格、最终成本、门店利润和资金余额必须分别表达。

## 八、跨模块共同需求与业务承接

本节只整合前述编号，不另增加重复需求。以下流程为整理建议；没有确定的条件明确留空待确认。

### 1. 五条主要业务流程

1. **供应商与协议**：基础资料 → 选择签约公司及合作内容 → 适用资料和协议 → 审批 → 盖章归档及生效 → 产品引用 → 按协议对账付款 → 续签或到期处理。审批通过和盖章归档谁是生效前提待确认。对应供01—16、外12。
2. **自营产品与团期**：行程及服务资料 → 产品定价依据 → 建立团期和销售范围 → 采购、分配资源 → 按渠道售卖 → 名单与资源执行 → 成本及结算 → 后续调整。具体日期售价和名额在团期／出行日期承接，订单保留实际成交依据。对应自01—33。
3. **外采产品**：供应商提交资料及两类价格 → 我方审核入库 → 授权销售 → 客户预订 → 供应商确认 → 按条件继续签约收款 → 实际成本与对账 → 财务付款。参考库存不代替供应商确认。对应外02—15。
4. **直营销售**：线索或历史客户 → 分配与意向 → 选择产品或单项服务 → 占位、报价及优惠 → 订单确认 → 合同、收款及认款复核 → 特殊要求交计调 → 退团、转团或转款。签约与收款的先后按已确认规则执行，不从附件自行补全。对应直01—23。
5. **加盟销售**：公司和门店授权 → 合伙人／店长／店员分工 → 查产品及授权价格 → 快速预订 → 必要折扣审批 → 合同及收款 → 出行 → 供应商结算与门店收益。出团时收益、最终收益、实际可提取金额分别说明。对应加01—18。
