# 数据中心报表页面字段、筛选与验收样例

日期：2026-09-13

本次步骤：用户在8页重整方案后要求“执行下一步”，据此推进页面字段、筛选、交互及样例设计。8页作为本轮设计方向；不将这句话解释为所有财务规则已确认，也不修改页面代码。

依据：《数据中心财务经营报表重整方案-20260913》《财务产品渠道周报附件核对清单-20260913》及四份项目控制文档。本文细化页面表达，不另造一套财务字段字典。最终财务决策统一记录在《待确认问题决策表》，本文中的样例假设不能代替拍板记录。

## 一、本次交付边界

1. 固定8页的默认字段、可选字段、筛选与页内视图，明确实际业务角色及处理边界。
2. 重点细化经营总览、产品经营、渠道经营、订单明细、回团明细；同时确定毛利、预算和报表管理的承接要求，避免前5页缺少口径和任务来源。
3. 提供一组可复算的订单及履约样例，另列毛利、任务、权限、刷新与发布验收。
4. 下一实施小批建议先制作“经营总览＋订单明细＋回团明细”，先让汇总与两种明细的阅读路径清楚，再扩展产品、渠道及管理页；这不是本轮已经实施。
5. 团期订单业务页面、成本确认、收付款、结算、审批及核算系统均不修改。不建设模拟数据跨模块自动回写。

## 二、待确认项怎样进入设计

下表RPT编号是《待确认问题决策表》中对应事项的编号，便于业务和财务对照，不是页面字段名称。

| 事项 | 本轮设计采用的表达 | 尚不能认定的规则 | 对应决策 |
|---|---|---|---|
| 主金额 | 明确显示订单净成交额、实际回团成交额、业务结算收入、财务确认收入各自名称 | 财务正式周报究竟以哪一个考核，跨期变化是否冲原期 | RPT-02、03、05 |
| 订单有效时间 | 提供确认日期和创建日期；创建用于查原始记录 | 正式有效状态和历史系统业务日期映射 | RPT-01、15 |
| 回团范围 | 实际完成业务完整列出，结算确认结果分开 | 待结算业务是否计入正式考核任务 | RPT-04、05 |
| 日期 | 自然月与财务回团管理月分别提供；每次显示起止日期 | 周界、双周起点、26日至25日最终适用对象、调整期间 | RPT-02、12 |
| 集团与组织 | 销售责任、产品责任和财务责任分开查看 | 实际公司名册、集团范围、内部利润归属及历史调整 | RPT-08、09、14 |
| 任务 | 有批准版本才展示正式完成率；无任务显示未设置 | 当年任务数、含税口径、层级拆分和版本选择 | RPT-13 |
| 毛利与供应分类 | 缺成本或税额时显示待确认；供应关系与经营分类分开 | 总额净额、税额、返点、甄选分类及多目的地分配 | RPT-06、07、10、11 |

已向用户提出主业绩金额与回团管理月份两个具体确认问题。未收到答复时保持待确认，不把推荐选项自动提交。页面原型可使用本文明确标注的演示假设，正式报表发布须采用批准规则。

## 三、共用页面规则

### 1. 阅读布局

页面顺序固定为：页面标题和数据版本 → 常用筛选 → 查询／重置／导出 → 关键金额摘要 → 页内视图 → 汇总或明细表 → 全查询范围合计与分页。图表只辅助观察趋势，旁边或下方有对应数值表，不要求点击图表取数。

报表结果不提供新增订单、确认回团、付款、结算等业务按钮，不设置每行一个“详情”弹窗。不强制设置操作列；P1至P6为只读报表。完整核对通过直接进入P5、P6并使用相同筛选完成，业务编号为可复制普通文本，不擅自恢复下钻。

P7、P8是真正管理对象，允许列表自身的编辑、提交、发布等动作；处理表单放当前页独立编辑区，避免层层弹窗。审批仍由审批中心负责，本原型只表达提交及返回结果，不模拟自动通过。

### 2. 筛选及状态

| 控件 | 适用范围与具体行为 |
|---|---|
| 数据版本 | 工作中最新结果／已发布版本；选发布版后固定该版截止、规则及任务版本，不与最新任务混算 |
| 分析范围 | 授权集团范围或公司范围；选公司后仅出现有效下级组织，不允许下级用户选择集团全部 |
| 时间 | 周、双周、月、季、年、自定义；期间选择后显示真实起止日，月视图额外区分自然月和已批准管理月 |
| 金额视图 | 订单净成交额／实际回团成交额；P4、P6确认视图使用专属收入成本口径，不给一个含义模糊的“收入”开关 |
| 常用归属 | P1选择销售或产品责任；P2固定产品经营责任；P3固定销售责任；P5、P6两类组织分别筛选，不相互覆盖 |
| 更多筛选 | 当前页展开产品类别、旅游范围、供应关系、经营分类、目的地、业务线、来源等；有条件但不适用某视图时须清空并明确提示 |
| 查询 | 点击后统一刷新摘要、表格、趋势、合计；修改条件尚未查询时不混合新旧结果，导出仍使用已查询条件 |
| 切换视图 | 保留有相同含义的已查询条件；日期含义变化须重新选择或确认，不能把订单确认日悄悄当回团日 |
| 重置 | 恢复当前用户授权范围及页面默认条件，不恢复集团权限，不改变已发布版的固有规则 |
| 导出 | 导出全查询结果而非仅当前分页，包含查询条件、金额单位、数据截止和版本；不导出无权查看的列 |
| 默认期间 | 已有发布版优先显示最近发布版；没有时显示工作版最近完整周。具体周界未批准时仅以演示周期呈现，不伪称正式周报 |

筛选条件过细而预算没有对应拆分时，实际仍可看，任务及完成率显示“该范围无对应任务”，不能把整家公司预算放到某一产品的分母。

### 3. 表格表达

- 默认展示当前视图最需要的字段，完整字段通过页内字段菜单选择；不得用“全字段”按钮再打开一层全量说明抽屉。
- 金额、单数、人次、百分比、单号完整显示；长产品名称允许省略但可展开文本。表格横向滚动不撑破页面，普通报表不硬加空操作列。
- 管理页有操作列时固定右侧且固定宽度；首个名称列吸收剩余宽度，不能把操作列拉成空白区。
- 每格最多3层内容，主数值与补充字段有语义分组。列名优先订单、团期、门店、销售组等实际叫法，不展示内部模型名称。
- 业务列表只保留一个主状态标签，数据完整性以弱文本或数量表达；查不到、未确认、不适用、无任务、真零分别呈现，不统一写0。
- 汇总行按全查询范围计算；订单数和团期数独立去重，不把多项明细行数当单数，不把层级小计再加入总计。
- 比率用汇总金额重新计算。结构表分母非正时不强画饼图或显示常规占比，保留金额及不可比较原因。

## 四、逐页字段及交互

### P1 经营总览

> 2026-09-14补充实施：销售与产品责任切换、8类责任分组、共同归属分类筛选、等长上期/上年同日比较、月年有业绩组织保留、三类任务与实际期间、趋势和本期来源导出已完成原型。集团5月任务算例仍为非批准演示，新增归属筛选后不得借用；正式同期、年度及同进度任务不补造。下表保留完整目标，已确认毛利、多期比较、发布版本等未因本批通过而完成；详见《经营总览补充原型验收记录-20260914》。

角色任务：集团或公司负责人、财务分析人员查看经营规模、比较趋势与目标。上游为订单、实际完成、批准任务和确认结算；下游为经营判断和两套明细核对，不改变业务单据状态。

| 页面部分 | 固定内容 |
|---|---|
| 常用筛选 | 分析范围、期间、销售责任／产品责任、组织层级、数据版本 |
| 摘要 | 本期订单净成交额、本期实际回团成交额、已确认业务毛利、已完成待结算金额；口径不同各自列名，不合成总收入 |
| 页内视图 | 订单业绩、回团业绩；确认毛利摘要标明独立确认期间，明细主入口在P4 |
| 默认主表列顺序 | 公司／事业部名称、本期金额、对比期金额、变动额、增长率、本月累计、本月任务、本月完成率、年累计、年度任务、年度完成率 |
| 可选列 | 单数、出游人次、同期累计任务、累计进度完成率、任务缺口、未归类金额 |
| 比较选择 | 上期／上年同期；列名和日期一同变化，可选择多期对照扩展列，不默认堆全部周月年比较列 |
| 补充区 | 最近8个同类期间趋势及数值表；截至截止日已售的未来完成安排；未齐来源影响范围 |

验收：选择A公司后金额、趋势与明细一致；切换产品责任后重新按产品组织分组，集团对外总额不增加；预算范围不匹配时不显示完成率。已确认毛利仅覆盖部分业务时必须显示覆盖团数和相关收入，不能冒充全部业务毛利。

### P2 产品经营分析

> 2026-09-14补充实施：四视图已采用P5/P6共同归属，新增领导/负责人及独立地理、管理分区、经营分类筛选和结构分析；补月累计、月年组织保留、比较/任务期间、金额缺数及完整来源导出。年度任务等不再笼统写“未设置”，明确为未提供批准任务；不读取P7草稿或集团月算例。下表为完整目标，正式同期、批准任务、历史时点和发布计划仍未实现，详见《产品经营补充原型验收记录-20260914》。

角色任务：产品、事业部及财务负责人判断经营组与产品结构。上游引用产品发生时归属和同一订单／完成明细，下游是经营资源安排和来源核对，不在报表编辑产品归属。

| 视图 | 默认字段及列顺序 | 专属筛选／可选字段 |
|---|---|---|
| 经营组业绩 | 经营公司、事业部／经营组、负责人、本期金额、上期金额、环比、同期金额、同比、年累计、年度任务、完成率 | 按经营公司／事业部／经营组选择一级汇总；业务线、旅游范围、产品类型 |
| 产品结构 | 产品类型或主归属目的地、自营金额、外采金额、待归类金额、合计、占本范围比例 | 供应方式与甄选如尚未形成互斥分类，不设相加的三列；甄选另筛选。批准分类后才替换正式列 |
| 渠道交叉结构 | 产品类型或目的地、所选渠道金额、全部授权渠道金额、该渠道贡献占比 | 渠道、门店／销售组；对比分母保留产品及期间条件，只解除渠道条件 |
| 跨年收客 | 下单年份、计划完成年份、已实际完成额、尚未完成安排额、已售合计、同期已售合计、同比变动额 | 订单截止日、目标完成年、产品组；计划年与实际年不混放一个可加总分组 |

单独提供“按实际完成年份”表，列为下单年份、实际完成年份、实际完成金额，未完成业务不进入该表。年度计划年份因延期变化时，发布版用发布当时计划，工作版用截止时已生效计划。

验收：多目的地只计一次；同一目的地的不同经营组可分别查看；内部共享业务在销售公司采购视角与集团产品分类视角不会被同时重复计入外采。预算没有目的地或产品拆分时不推算分类完成率。

### P3 渠道经营分析

2026-09-14实施说明：四个基础视图已完成，详见《渠道经营基础版原型验收记录-20260914》。本批按整体计划阶段3实现期间查询、本期业绩、同期任务缺数表达和来源核对；下方完整周/月/年任务宽表、正式对比、权限及员工任职期间仍为目标。无批准来源不借用集团任务，渠道毛利计算留阶段4，预算管理单独下一批。

角色任务：渠道、门店和呼叫中心负责人比较业绩、分解任务差额。上游为订单发生时销售归属、渠道、任职及任务；下游仍由销售场景处理客户业务，不生成催办或人员考核结论。

共用金额列顺序：本周金额、上周金额、周环比、本月金额、同进度同期金额、月度同比、月任务、月完成率、年累计、年任务、年完成率。宽表允许切换“周对比／月任务／年累计”列组，默认月任务组。

| 页内视图 | 固定识别列 | 更多筛选／扩展信息 |
|---|---|---|
| 渠道与区域 | 预算区域、渠道大类、具体渠道 | 销售公司、经营性质、来源系统；区域和行政区划分别筛选 |
| 门店 | 门店名称、销售公司、经营性质、预算区域 | 直营／加盟等正式分类、开关店期间、销售人员；新店与原店可比范围需批准 |
| 呼叫中心 | 销售组、顾问姓名、员工编号 | 按组汇总时不显示顾问列；个人表扩展任职有效期、任务适用级别，不展示证件和无关人事信息 |
| 渠道产品结构 | 产品类型或目的地、金额、占本渠道比例、相同产品全渠道金额、该渠道贡献比例 | 供应关系、经营分类、业务线；两种比例明确不同分母 |

切换“订单／回团”时，金额日期和对应任务同步变化。切换门店与呼叫中心时清理不适用的门店／组员条件，不能沿用残留筛选造成空表。未分配销售组或未知渠道显式列出，不塞进“其他”掩盖缺失。

验收：公司、渠道、门店及组员在同一互斥分组层次的合计一致；某顾问后来调组不自动改写发布版；门店或组长只看授权范围，汇总和导出不得暴露别的公司或个人。

### P4 团期毛利与结算分析

2026-09-14实施说明：基础版已完成，见《团期毛利与结算分析基础版原型验收记录-20260914》。实际为团期利润、经营组毛利、待确认与异常、结算后调整四视图；共同回团明细与独立结算算例分开。下表完整目标中的不含税专属结果、财务确认期间查询、返点补充、同期与批准任务暂未实现，仅部分可选字段显示缺资料。原结算金额保留，金额按固定资料截止包含生效调整，不是任意历史余额；本批不改源业务，下一步P10采购返点另批。

角色任务：产品负责人、计调管理及结算会计看已确认利润和未确认缺口。上游为实际完成、结算收入及有效成本，下游只是成本或结算责任定位，分析页不确认成本或提交付款。

| 视图 | 默认列顺序 | 其他字段 |
|---|---|---|
| 团期利润 | 团号／项目号、名称、产品经营组、实际完成日、结算确认日、业务结算收入、确认成本、业务毛利、毛利率、结算状态 | 负责人、团控、销售单数、确认收入覆盖、成本缺口数量 |
| 不含税结果 | 团号、财务确认期间、不含税收入、不含税成本、不含税毛利、毛利率 | 业务结算期间与财务确认期间分别筛选，不用页面税率按钮重算 |
| 经营组毛利 | 经营组、确认期间、结算收入、成本、毛利、同期毛利、变动额、毛利任务及完成 | 只有同确认口径的批准任务才能比较 |
| 待确认与异常 | 团号、名称、实际完成日、结算状态、成本未确认金额或缺项数、待结算成交额、结算后调整额 | 负毛利作为筛选及数字表现，不与结算主状态抢标签 |
| 返点补充 | 供应商、关联团期、预计返点、已确认返点、确认期间、计入成本或收益方式 | 协议依据、分配依据、调整记录；不增加付款操作 |

收入或成本覆盖不完整时毛利显示待确认，部分已确认成本仍可核对；不同币种或含税口径不能相减。预估成本可选查看，不加入确认成本。来源“未提交准单”在扩展来源列展示，定义未定不建立新的系统主状态。

### P5 订单明细

角色任务：财务和授权负责人核对有效成交组成。上游为已生效销售内容及调整；下游为P1至P3的明细证明，不替代销售业务订单列表。

| 部分 | 明确字段 |
|---|---|
| 默认视图 | 按订单确认期间查看截至数据截止的净值；正式周报是否采用本视图待RPT-02、03确认 |
| 默认列顺序 | 订单号、销售内容／产品、确认日期、订单状态、团号或服务日期、销售公司、门店／销售组、销售人员、产品经营组、主成交渠道、数量及单位、净成交额 |
