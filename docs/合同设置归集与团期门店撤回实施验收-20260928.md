# 合同设置归集与团期、门店改动撤回实施验收

日期：2026-09-28。依据：用户明确撤回原方案第三项“门店可以使用哪些合同”和第五项“某个团期的实际安排如何进入合同”，并要求合同模板、合同规则合并为两个 Tab。本文是该范围的最新依据，覆盖早期 C02 门店扩展和 C05 团期新增资料的实施描述。

## 二、业务规则和开发承接

1. 合同管理员从合同设置集中维护文本及办理规则。规则仅迁移入口，不因此改变原审批、签约付款或模板适用条件。
2. 门店本轮多模板扩展明确撤回，不再据历史方案开发“允许合同范围”复选组或批量授权。已有门店配置和公司、模板资格校验保留。
3. 团期本轮合同专用资料模块明确撤回，不再要求开发新的团期资料版本、影响核对抽屉及新建团期合同附加校验。来源仍复用现有产品、团期和订单事实，本次客户选择由合同准备承接；这次撤回不代表合同必填资料可以空缺。
4. 本次不修改合同准备、多人签署、审批、变更、归档，以及已完成的产品“沿用系统设置／指定合同模板”简化。原型没有增加跨页自动同步或真实12301接入。
5. 历史实施报告保留当时证据，但涉及本次撤回范围的条目不再作为待恢复功能；最新边界以本文和用户指令为准。
