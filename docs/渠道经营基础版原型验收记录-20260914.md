# 渠道经营基础版原型验收记录

日期：2026-09-14。范围：整体完善计划阶段3、小批顺序第4项中的渠道经营基础版。结论：本小批原型通过，预算任务管理单独实施；不代表正式财务规则、权限、取数或毛利计算完成。

## 一、角色、来源与入口

入口：数据中心 > 经营报表 > 渠道经营。页面为 `merchant/data/channel-reports.html`。本机预览为 http://127.0.0.1:8002/merchant/data/channel-reports.html；原8000服务返回空响应，8001为其他服务，未停止或替换原服务。

主要角色是财务经营分析、渠道负责人、门店及呼叫中心负责人；高频任务是看成交、实际完成、销售责任和产品贡献，核对归属缺失。上游是订单发生时销售归属、产品归属、实际完成及金额分配；下游是经营判断和来源核对。本页不修改归属、审批、收付款、收入或成本。

依次阅读四份控制文档，盘点数据目录、导航、共享报表与测试，再对照P3字段方案、整体计划及呼叫中心业绩页。呼叫中心原页保留顾问/来源/产品转化等销售运营职责，不用旧固定转化业绩拼财务周报。当前渠道页引用已补充的两套明细样例，未读取或改造源业务页面。

## 二、页面验收清单

| 页面位置 | 本批功能 | 核对重点 |
|---|---|---|
| 渠道与区域 | 主渠道、预算区域与渠道、销售公司、销售部门四种汇总 | 主渠道互斥；公司、事业部、部门不作为可相加的重复层级；未知区域单列 |
| 门店 | 按销售公司与门店汇总，展示门店性质和预算区域 | 引用发生时资料；不从门店名字猜直营加盟，不虚构未提供门店业绩 |
| 呼叫中心 | 中心、销售组、顾问三级切换；顾问包含员工编号 | 同名顾问按独立演示编号区分；缺编号不按姓名误并；组、中心与个人合计一致 |
| 渠道产品结构 | 产品类型、主目的地、供应关系三种结构 | 展示所选范围金额及占比、同范围全部渠道额及渠道贡献，两种分母分别核对 |
| 业绩口径 | 订单成交与实际回团切换 | 订单按确认日期及截止时净值；回团按实际完成及分配成交额，包含待结算和跨年订单 |
| 期间 | 自选、近7日、月累计、年累计，以结束日计算 | 近7日不冒充已批准自然周；不把全年未来安排当实际完成；日期不能越过演示截止 |
| 责任与业务筛选 | 销售/产品公司、产品组、部门领导、门店、组、顾问、预算区域、主渠道、获客来源、产品类型、旅游范围、供应关系、目的地、业务线及来源 | 销售和产品责任分别筛选；公司/渠道变化清理部门组员；门店和呼叫中心切换清理不适用条件 |
| 金额列组 | 本期业绩或同期与任务；可选渠道毛利状态 | 缺完整同期、批准任务、毛利依据时不生成增长率、完成率或利润 |
| 缺数 | 销售归属缺口、成交金额缺数，可筛选 | 未归类业务不丢弃；已知金额与缺数同时显示，全未知金额非0，缺金额不计算结构比例 |
| 来源核对 | 当前页展开来源明细，含订单、业务明细号、业务日期、归属、来源及版本 | 无业务下钻、弹窗或财务操作；来源和汇总使用相同查询，实际完成号区分阶段 |
| 显示与导出 | 可选领导、事业部、来源、归属确认日及版本；排序、分页、空态、全查询导出 | 待查询条件不影响已有结果和导出；导出含已查询筛选、日期、单位、缺数、汇总方式及完整来源明细 |

## 三、样例与规则验证

1. 默认订单6条销售内容、5单、54,000元；主渠道为门店15,000、呼叫中心29,000、企业直销10,000元。官网咨询与电话成交是获客来源和主渠道的不同描述，不额外加一次成交。
2. 销售A公司35,000、B公司19,000元；销售A/产品B组合10,000元，内部供应不增加集团对客成交。未知预算区域9,000元、未知主目的地19,000元仍保留。
3. 实际回团56,000元，门店17,000、呼叫中心20,000、企业直销19,000元。包含上年订单完成15,000元；项目第一阶段4,000元，不把余下6,000元计划安排计入实际。
4. 呼叫中心按中心、组和个人合计均29,000元；两个同名王宁使用不同演示编号。独立测试同一组重名、缺员工编号、未知渠道和未分配组，不修改默认订单金额。
5. 呼叫中心跟团29,000元，占该渠道所选范围100%；同类全部渠道39,000元，贡献74.36%。解除主渠道时保留公司、产品、门店及销售组条件，不借用更大范围分母。
6. 年累计订单按2026-01-01至05-07得到59,000元，与默认05-01至05-07的54,000元不同；期间切换实质参与查询。没有完整对比期资料，不把某个对比期间的空样例当0计算同比。

员工编号仅为新页用于区分演示人员的补充资料，不是正式员工名册，未写回原报表或源订单。组织和分类仍取发生时明细，不读取P8当前会话草稿覆盖历史。

## 四、设计取舍与遗留

原完整P3设计的周对比、月任务、年任务宽表，本批收缩为可查询期间、本期业绩与同期任务缺数表达。缺完整历史来源、批准任务和正式统计日历时，不借用集团任务、不默认均摊、不计算伪增长。门店开关店期间及可比店范围、正式员工任职有效期间仍需来源；本批展示已有归属日期和版本，不冒充完整人事档案。

渠道毛利只显示规则及资料待确认。升舱与优惠承担还原公式、10%比较方式、成本分配和确认金额留整体计划阶段4；不按整团成本或外采佣金比例推渠道利润。体验中心、加盟门店、全员营销等未提供演示业务，不伪造金额；正式纳入范围及权限仍需确认。
