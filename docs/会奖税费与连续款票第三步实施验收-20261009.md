## 一、本步产品判断与结果

本步已完成收入／成本税费测算、票面识别样例与人工复核、预计／核定区分、项目团原位款票申请和财务电子开票状态。没有新增菜单或独立HTML，也没有恢复已撤回的建档改造。

业务说“开专票后除税率算毛利”，应拆成三件事：业务测算、票面资料、财务核定。不能仅凭票种决定整个项目的计税方式，也不能把票面税额全部作为可抵扣额。选择适用单一税率的测算时，10,600元与6%得到10,000元和600元；混合／差额等情况可登记财务提供税额及依据，未明确保持待确认。含税换算公式及扣税凭证范围参照[增值税法实施条例第十一、十二、十六条](https://fgk.chinatax.gov.cn/zcfgk/c100010/c5246349/content.html)，具体公司及业务的适用方式仍待财务确认。本原型没有替财务批准税收政策。

数电发票已有官方推广及交付依据，本轮仅表达申请、财务审核、办理状态和结果文件，参照[国家税务总局数电发票推广公告](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5236067/content.html)。下载文件明确标注为无交易金额的原型PDF样例，不是税务发票；人工上传已有结果保留为备用办理方式。

## 三、关键字段和联动

### 收入与成本

- 收入测算方式默认待财务确认，可选“按已确认的单一税率测算”“按财务提供税额测算”。非待确认方式必须填依据；没有依据不能借默认6%形成确定毛利。更换方式显示对应税率或手工税额。
- 成本一直录入含税金额。预计票面税率使用本公司启用的0%、1%、3%、6%、9%、13%选项，选择某税率不代表该业务当然适用。根据金额与税率算票面未税金额／税额。
- 预计可扣处理分待确认、不可扣、预计全扣、部分可扣。不可扣取0，待确认保持空，全扣按预计票面税額，部分可扣需输入有效金额；选择有结论的处理必须有依据。财务仍核定最终可扣金额。
- 项目按原采购计一次；本场取原直接费用和明确分配。共同费用预计税额按明确承担比例测算，分场核定额由财务登记，不拿预计比例充核定结果。
- 税额未明确、采购未确认、整包未分场、没有有效收入或成本等情况，相关毛利显示待确认。各币种分别展示，未取得可靠折算不合并。
- 批准价款变更清除旧销项税核定，保留原依据；单一税率继续按新含税金额测算，手工税额转待重新测算。新增成本调整不复制原费用的发票和可扣税额。

### 票据识别与差异

识别仅为明确标注的演示样例，不读取真实OCR服务。先上传PDF或图片；多附件需选择本次票据。样例覆盖识别一致、税率不一致、识别失败、多税率。结果显示票面含税金额、税率及税额；未核对不能保存。

采用识别结果写入票面字段。所选票据覆盖整笔费用时，预计税率随实际票面更新；只覆盖部分费用时保留整笔预计，避免用局部票据覆盖全部成本。含税采购金额不变，也不会自动成为财务已核定。人工保留或识别失败需要说明及完整票面资料；多税率按原票逐项核对后填合计，不套一个比例。

原税率、预计可扣处理及票面资料保留在修订历史；费用详情与收入测算内可展开“税费核对历史”查看。票据来源被移除／替换须重新核对。金额、币种、供应商或票面关键字段改变，原财务核定值转历史，当前回到待核定。

### 开票与收款

本场抽屉只针对明确选中的订单。年度项目合并多订单办理继续在原销售办理入口进行；本场查看合并申请可看完整来源，但修正合并单要回原申请页核对全单，不能只改其中一笔。

申请带入客户、我方公司、币种，选择专／普票、本公司有效开票项目，填写税号、金额、备注、收票资料及可选申请税率。财务完整查看原文和换行，核对单一税率或按服务明细处理；发票税率不直接替代整笔订单的销项税核定。

| 状态／动作 | 金额与恢复行为 |
|---|---|
| 待财务办理 → 审核并开票 | 重新核对公司、客户、币种、订单及可申请额；保留本次请求编号，进入开票中；不计已开 |
| 开票中 → 查询未知 | 进入结果待查，继续占用可申请额，只能查询，不能新发同一申请 |
| 查询明确失败 | 显示原因，不计已开；明确失败释放本次占用 |
| 失败 → 重试 | 沿用原申请，重新核对可用金额；其他申请已占余额时阻止重试 |
| 成功 | 已开金额只增加一次，保留结果编号、日期、备注和记录，可下载样例PDF |
| 退回补充 | 原内容与原因保留，业务修正并重提原申请，不复制一张新单 |
| 历史已开但申请明细未迁入 | 已开金额仍占用可开余额，不因缺明细释放；与已开申请记录取一致口径，不重复相加 |

正常或异常处理仍只表达当前浏览器的原型记录，不生成真实银行流水、真实税票、核销或会计凭证。
