# 部门费用新增与验收

2026-09-15｜按用户指定仅实施月度损益的部门费用；门店分润留下一步。

## 角色和业务位置

公司财务、管理会计、部门负责人核对各部门承担的费用。上游为已确认费用及批准分配记录，下游用于部门经营分析和回源核对；页面不做费用录入、分配审批、内部结转或付款。与费用构成（按费用类别）、部门损益（收入成本及经营结果）分别为独立主题。

沿用当前月度损益的同一份费用模型及版本，不生成另一套费用，也不改公司损益计算。原始费用确认额与分配额不能在同一明细重复累计。

## 交付边界

- 仍是2026年9月等固定独立费用算例，未接真实费用、正式人员授权、预算及分配审批服务。
- “未分配费用”不是一个真实部门；该行承担为0，金额在未分配列，防止强摊。
- 已知公司费用范围不完整时，相关金额显示缺数。不能把明细已有部分当公司完整费用。
- 内部管理结转保持独立Tab，本次不把结转200再记费用；费用类别仍可用部门条件筛选，但主维度始终费用项目，不再切成部门主题。
- 部门费用预算差异、历史同期及完整正式费用分类仍属后续预算/比较要求，本次不提前销项。
- 成本构成、原公司与部门损益、集团调整及并行门店办理/交付计划保留；原8批不重开。
