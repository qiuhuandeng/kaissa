# 成本构成新增与验收

2026-09-15。按用户最新指令，本步仅做“业务毛利 → 成本构成”；部门费用、门店分润后续按用户顺序推进，不执行产品考核、统计日历或来源核对。

## 角色、业务位置与边界

产品财务、结算会计、计调主管按团期或服务核对成本花在哪里、结算比预计增减多少及单位成本变化。上游应为业务预计成本及已确认结算成本项，下游用于业务毛利分析及回源核对。页面只读，不维护预计、不确认结算、不生成应付，不以付款或预付代成本。

核对了团期结算页面及成本业务核对文档：原页面成本、付款存在独立示例或推算，不能拼成实账。本次单独建立明确标记的成本算例，不改源办理页或既有毛利计算，不宣称跨页实账已打通。

## 计算及资料边界

- 一条算例是某团期或服务承担的一项成本，不是多团共用采购单全额；未知成本不能用估算付款代替。
- 数量是各费用项的计价数量，不是去重游客人数。不同项目或单位的数量不做全公司合计。
- 当前默认业务完成日期2026-09-01至09-30，资料截至09-30。全部数据为独立固定算例，支持截止前确认范围查看，不支持超出已提供日期的未来资料。
- 预计版本与两侧金额分别保留；预计及结算缺金额/依据时不计完整差额。结算数量缺失只限制单位成本，不抹掉已知金额。
- 合计只按公司和币种分别列金额，跨单位无数量/单位成本合计；任一成本项未知则对应完整金额合计未知，不把已知小计冒充完整成本。
- 本次只交成本构成。毛利明细预计对照、取消损失、成本后续调整链及正式账务政策仍属其他需求；不把本页“差额”当成本审批或法定损益。
- 已知缺口：真实成本类别与科目对应、正式预计及结算版本、完整成本来源、真实授权及接口未接；算例说明业务核对方法，不构成财务批准。
