# 订单收付与往来账龄原型验收记录

日期：2026-09-14。原第2批，执02至执05原型验收通过；非正式财务取数或政策批准。

## 角色、来源与边界

应收应付会计及财务分析人员从财务的“财务报表”进入，报表主题选择“订单收付与往来账龄”。上游为已确认应收应付、调整、核销及到期日变化，输出截至指定日期的余额、账龄和内部待清算。核销是用已确认款项或批准冲抵减少相应欠款。已核销包含非现金冲抵，不能全部称客户已收或供应商已付。

页面路径：`merchant/finance/finance-reports.html?report=balances`。旧`ar-ap`入口复用新主题，不再运行旧往来算法。正常使用不需要固定端口，本地HTML通过右上主题选择进入。

源代码与文档已成对核对：应收页的阶段应收、确认与调整；应付页的账单、付款申请占用、预付冲抵；财务流程01/02与多主体责任基线。应收原型缺完整历史，旧往来以结算收入代已收且逾期固定零；应付的可申请金额不是账面余额，源页面无可复原历史。均不作为正式报表来源，不改办理页。
