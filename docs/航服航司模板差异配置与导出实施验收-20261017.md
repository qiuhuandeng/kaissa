# 航服航司模板差异配置与导出实施验收

日期：2026-10-17。步骤：完善01。依据附件C4、I2、[附件差异复核](航服附件与原型差异复核-20261017.md)及进度第四节。本次完成既定计划最后一步；验收以页面内容、功能操作、实际文件和跳转流程为主。附件中的航司名称和功能要求是需求证据，未提供的正式格式不按推测补成已批准标准。

## 一 本次交付与业务位置

配置人员在「系统设置→航服设置→名单模板」按航司和版本维护低频导出规则；票务在「机票订单详情→名单出票→航司模板」选择格式、查看实际名单并下载。上游为当前订单乘客、实际航段及各段舱位餐食；下游为票务取得文件后按正式受理规则办理出票，不在配置页面代替出票或财务确认。

保留12家航司、24个演示版本，原文8家均包含。现在有18列中文和14列英文两种不同的默认演示格式。法国航空、土耳其航空、卡塔尔航空及阿联酋航空的2026.2用于演示英文格式，**不是这些航司的正式样板**。其余默认中文格式；所有版本均可独立配置。

|---|---|---|---|
