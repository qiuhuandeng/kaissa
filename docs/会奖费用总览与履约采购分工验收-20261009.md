# 会奖费用总览与履约采购分工验收

> 本文保留上一轮职责分工与金额测试的历史证据。其中“详情跳采购页再新增、台账先选项目、付款和结算三块卡片”的交互已由[会奖费用采购原位交互验收-20261009](会奖费用采购原位交互验收-20261009.md)替代，不再作为当前操作说明。

2026-10-09，按用户对“项目费用与项目团费用采购”的讨论及随后“执行”指令完成。单团项目负责费用总览，实际采购统一在履约办理；项目共同费用和跨场采购仍归所属项目，不建立虚假活动。单次／多场建档规则维持用户撤回后的版本。

## 1 角色与操作路径

| 使用角色与任务 | 入口与处理内容 | 完成后的去向 |
|---|---|---|
| 项目负责人核对整体开支 | 单团项目详情 → 费用总览：原批准预算、最新预计、各币种确认费用及待确认笔数；直接费用／共同费用／跨场采购构成；逐笔费用只读 | 费用详情 → 查看采购，进入原费用所在的履约采购范围；返回原费用总览 |
| 计调维护本场采购 | 履约中心 → 项目团 → 详情 → 费用采购：新增本场费用、维护采购、调整本场预计 | 同一费用用于请款、供应商对账及后续业务结算；业务确认不等于实际付款 |
| 有采购权限的项目负责人员处理共同采购 | 项目团列表右上角“项目采购”，或详情中的项目共同／跨场采购入口 | 在原履约费用页选择项目范围，新增共同费用或跨场采购，核对服务交付及分配；请款仍引用原采购 |
| 财务办理付款与核算 | 保留原付款复核、实际付款和税额核定入口 | 项目和活动查看办理结果，不在总览代办财务确认 |

未选择项目时不默认打开第一条演示项目，也不提供新增费用。选择仅有一场有效活动的项目时默认本场采购；项目范围仍可从范围选择框进入。多场项目默认共同／跨场采购，再选择具体活动。此项仅改变费用入口的默认范围，不改变建档的单次／多场规则。

## 2 页面与表单变化

| 页面 | 本次变化 |
|---|---|
| 单团项目详情 | “项目费用”更名“费用总览”；移除费用新增、编辑、分配、调整预计、请款与撤回操作；保留只读预算、费用构成、明细及已有税额测算。新增履约采购入口，明细详情反查原采购 |
| 项目团列表 | 工具区增加“项目采购”，沿用查询中的项目；不增加菜单，不在列表行添加重复费用按钮 |
| 项目团详情的费用采购 | 新增按钮明确为“新增本场费用”；确认金额列改“本场承担”；跨场采购标“采购分配”，共同费用标“管理分摊”，采购总额弱化显示。分配记录只读；请款、调整返回原采购办理 |
| 原履约费用页的项目分支 | 作为“项目采购”工作区，归属履约中心／项目团；选择项目及项目共同／跨场或具体活动。项目范围仅列共同及跨场采购，付款申请按同一范围展示；保留已有业务结算入口 |
| 共用费用抽屉 | 沿用餐厅库抽屉规范及已有采购字段；新建时明确费用范围，编辑时不直接改变既有归属；不能把金额改到低于已分配合计 |

共同费用的未分摊部分保留为项目共同金额；跨场采购未明确归属的部分显示待分配。共同费用的管理分摊不新增费用，也不增加项目总额。本场预算未提供分配依据时显示“—”，不把整笔采购预算当作本场预算。

费用调整的草稿及退回修正统一返回原履约采购；财务调整记录保留查看，不在财务页另录业务采购。只读入口在实际操作函数中也受限制。销售无采购修改权限，协作及跨公司来源不能通过自动打开费用详情看到受限资料；活动归属核对同时支持活动详情和采购工作区。已结项项目禁止新增和请款，仍保留原有费用调整路径。
