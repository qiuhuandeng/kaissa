# 88｜页面修改与新增设计指令

## 88-01｜供应商查重与准入

| 页面中文名称 | 文件名 | 修改/新增 |
|---|---|---|
| 供应商管理 | `merchant/resource/suppliers.html` | 修改列表搜索及准入抽屉 |
| 供应商详情 | `merchant/resource/supplier-detail.html` | 增加合作申请承接 |
| 审批中心 | `merchant/approval/approvals.html` | 完善供应商审批处理 |

### 页面设计指令

1. 供应商管理：在“新增供应商”抽屉顶部增加查重区，输入公司名称、证照或注册编号后显示匹配结果。命中同一供应商时选择“申请本公司合作”，带入主档；近似名称显示核对提示，不自动合并。
2. 供应商管理：准入表单按“基础资料、合作申请、资质附件、财务资料”分区。基础资料包含公司全称、英文名、品牌名、企业类型、注册地、注册地址、经营联系地址、法定代表人及电话、总经理及电话、业务联系人及电话/微信/邮箱。
3. 供应商管理：企业类型支持适用的多选分类；合作申请独立填写提供的服务、申请公司、部门、负责人及合作原因。服务范围支持地区、国家、城市多选，列表搜索同时支持逐级选择和直接搜索单一目的地。
4. 供应商管理：资质清单按企业类型和注册地切换，展示营业执照、适用的经营许可或等效材料、责任保险及报价单。责任保险不默认必填；材料适用规则未配置时显示待配置，不把旅行社许可强制用于所有类型。
5. 供应商管理：财务资料使用可增删的账户明细，包含开户名称、银行、银行地址、账号、币种、适用公司及国际银行识别代码。每个账户单独显示待审核/已审核/退回，填写完成不自动成为可付款账户。
6. 供应商管理：增加“正式合作/临时合作”选项。临时合作填写一次性服务范围、期限、原因、联系人和适用资料，生成不重复的临时编号；转正式保留原档案和原编号关联，转换规则未配置时只允许保存申请。
7. 供应商管理与审批中心：实现保存草稿、提交、撤回、退回修改、重新提交及查看审批记录。审批结果显示在对应申请详情，资料缺项定位到具体字段；准入状态、协议是否可用、账户是否可付款分别显示。
8. 供应商详情：新增合作申请后展示申请公司、合作内容、联系人和审批状态；同一供应商新增第二家公司合作不重复建立主档。

## 88-02｜公司协议、协议文件与到期处理

| 页面中文名称 | 文件名 | 修改/新增 |

| 公司协议共用脚本 | `shared/supplier-company-agreements.js` | 修改有效协议及历史引用判断 |

### 页面设计指令

1. 供应商详情：在“公司合作与协议”区域按公司展示部门、合作内容、有效期、联系人、账期、平台使用费、返佣及适用条件。通用联系人与公司合作联系人分开维护，切换公司同步切换协议和联系人。
2. 供应商详情：新增合作公司、续签和修改协议分别生成申请，复用供应商基础资料；新申请未生效时不覆盖该公司的有效协议。
3. 供应商详情：增加“协议文件”区域，提供选择模板、带入双方资料、预览、保存版本、上传双方盖章件、查看替换历史及下载。缺少模板所需字段时定位缺项，修订已生效协议时生成新版本。
4. 供应商详情与审批中心：分别展示协议草稿、审批中、退回、待补盖章件、生效和到期的处理结果；生效条件按配置校验，未配置时显示待配置并阻止直接生效。
5. 供应商详情：增加临期/到期筛选及提醒规则抽屉，维护适用公司、接收岗位、提前天数和提醒方式，预览拟提醒时间及记录；演示提醒与实际发送结果分开标识。
6. 公司协议共用脚本：新业务仅引用对应公司、合作内容和有效日期内的协议；一家公司的协议到期不影响其他有效合作。历史成本及付款继续显示原协议版本、账期和责任，不自动替换成续签协议。
7. 供应商详情：产品区按所选公司展示授权产品和业务联系人；法定代表人、银行账户、费用返佣及内部备注按岗位限制查看，预览和导出使用同一权限范围。

1. 自营产品编辑：复制产品时允许选择另一出发地，复用目的地行程并分别填写发起公司、实际地接供应商；清除旧团号、库存、有效报价及审批结果。
2. 自营产品编辑：每日行程增加可增删、排序的交通段，字段包含交通类型、起止地点、出发/到达日期时间、航班或车次及服务说明，支持同日多段飞机、火车和混合交通。
3. 自营产品编辑：在行程服务中按日期、地区或服务段关联多家地接供应商，分别填写服务内容、责任人及公司协议，不能只用一个主供应商代表全部服务。
4. 自营产品编辑：购物和自费项目改为逐项录入，关联行程日、国家/城市、名称、说明及适用的金额/币种；图片识别结果进入待核对列表，确认后才带入行程。
5. 自营产品编辑：导游、领队服务改为多选，可补充分段服务说明；“无导游”与有导游服务互斥。参考酒店支持多条，展示住宿类型、平台评分及来源、星级或非星级、所在地；营地等不强制填写星级。
6. 自营产品编辑：增加资料导入处理区，支持Word、PDF、粘贴内容及产品链接，按“来源→识别草稿→逐日核对→修正→确认带入”操作。缺日期、错日、缺酒店和识别失败分别给出提示，取消带入不覆盖原内容；演示识别结果明确标记为演示稿。
7. 自营产品编辑：产品名称允许括号、星号等业务符号并安全显示；报名须知支持完整长文、分段编辑和版本，包含适用的护照、汇率风险、保险说明，途经城市支持多选。
8. 产品详情：按天展示交通段、地接服务、酒店、购物及自费项目；增加手机宽度预览，图片、长名称和长须知完整可读，折叠后可展开查看全文。

### 页面设计指令

1. 团期管控：批量建团增加节假日/周期选择、生成日期预览、逐日排除和重复日期提示；提交只生成勾选且不重复的团期。
2. 建团表单：支持“选择已采购资源”和“先建团后分配资源”两种方式，分别展示采购数量、本次分配数量、对客名额、最低成团人数及资源单位；资源未落实时显示供应确认方式。
3. 团期详情：基本资料维护出发地、集合地点/时间、计调、领队、允许销售门店和适用销售规则；人员未确定可保存草稿，出团交接区显示具体缺项。
4. 团期详情：内部建团默认不对外发布；官网、小程序等销售渠道分别设置发布开关和有效范围。发布前校验日期、有效售价、授权门店及供给方式，失败时定位缺项。
5. 团期管控：调整名额、停售、复制、取消出发按团期主状态显示。停售只关闭新销售；复制不带原订单、合同、收款和资源占用；已有订单或成本的取消进入变更影响处理。
6. 团期详情：关闭某渠道销售后仍可查看该渠道历史订单；未授权门店不能新增订单。

**执行状态：已完成（2026-09-18）。** 四页原型、计算、正常/异常及版本隔离浏览器验收见[88-05实施与验收](88-05定价附加项目佣金规则实施与验收-20260918.md)；订单采用和佣金结算仍由88-16、88-24承接。

| 页面中文名称 | 文件名 | 修改/新增 |
|---|---|---|
| 产品定价 | `merchant/product/product-pricing.html` | 修改价格配置、版本及试算 |

### 页面设计指令

1. 产品定价：分开维护标准销售价、建议零售价和供应商结算报价，显示适用日期、团期、规格、币种和有效期；价格草稿、审批中及已生效版本分开，未批准版本不能覆盖在售价格。
2. 产品定价：设置淡旺季、早鸟/尾单、人数、出发地条件，提供试算抽屉，输入日期、人数、出发地及渠道后展示命中规则和计算结果；互斥或优先级未配置时显示具体冲突，不随机选价。
3. 团期详情：附加项目维护单房差、联运、升舱等项目的单价、计量单位、数量范围、适用人群、日期及是否需资源确认；参考价、待报价和有效销售价分别表达。
4. 产品定价与团期详情：价格构成按标准依据、条件定价、营销减免、特批调整、最终应收顺序展示；分担金额仅解释优惠承担，不再次抵减应收。标准10000、早鸟价9500、券减300时结果显示9200。
5. 佣金规则：设置团期、产品、渠道、顾问适用范围，维护计算基础、金额或比例、有效期、审批版本和冲突优先级；同时命中多条时展示是否可叠加及原因，佣金与退改规则分别配置。
6. 审批中心：价格/折扣申请显示调整前后、理由、适用范围和申请人，支持通过、退回、撤回及重提；退回后继续使用原价，加盟自主定价权限未配置时只允许发起价格申请。

## 88-06｜交通采购、分期付款与团期分配

| 页面中文名称 | 文件名 | 修改/新增 |
|---|---|---|
| 交通采购 | `merchant/tour/resource-procurement-inventory.html` | 修改机位、舱房、铺位采购详情及变更 |

### 页面设计指令

1. 采购详情：按规格展示采购总量、已分配、未分配、已占用数量、单价、金额及单位；机位用座、舱房用间、铺位用铺，旅客人数另列，单位换算必须显示依据。
2. 采购详情：增加团期分配处理区，选择团期、规格和数量，预览分配前后结果；支持退回未使用分配及再分配，已占用部分不能直接收回。
3. 采购变更抽屉：逐规格填写新数量，展示原数量、已分配/已占用、变更后未分配、金额及免费退回期限；每个规格独立计价，数量或金额为零时保存零，不回填原值。
4. 采购变更抽屉：新数量低于已分配或已占用时列出受影响团期和缺口，保存为待处理变更，不直接生效；处理资源分配或售后后重新核对。采购100、已分配60，减至80显示未分配20，减至50显示冲突。
5. 采购详情：付款节点维护一押、二押、三押的金额/比例、条件、截止日、免费退量比例和期限；到期处理生成可审核申请草稿，重复操作不重复生成，同一节点显示申请及实际付款记录。
6. 邮轮采购：按舱型维护房间数、单价、入住人数换算和分配结果；专列采购按席别/铺位维护数量、价格档和分配。实名、退位及损耗规则未配置时显示待配置，并限制依赖该规则的生效动作。

### 页面设计指令

1. 订单预订：记录团期、销售渠道、分销商/门店、顾问、占用数量及资源单位，默认带入登录归属；未授权用户不能切换渠道规避配额。
2. 团期详情：释放名额时选择原订单和实际占用明细，展示原渠道、可释放数量、本次数量及释放后余额；结果保存到原占用记录，重复处理不再次增加名额。
3. 团期详情：渠道配额调整使用一个独立处理区，显示各渠道配额、已占用、调前调后数量及原因；不能低于已占用或突破可分配总量。渠道表格不增加只提示同步成功的操作按钮。
4. 售后处理：分别展示取消/转团的资源处理结果和款项处理结果，按实际占用单位释放到原渠道；占位到期使用适用规则，期限未配置时显示待配置，不自行生成默认时长。
5. 团期订单及详情：展示销售门店、分销商、顾问及原占用依据，团期详情提供进入独立订单页的入口。
6. 团期详情：释放后重算原渠道可用额。例如代理配额10、已占6、可用4，释放2后显示已占4、可用6；其他渠道保持原数，舱房及铺位按实际占用单位处理。

## 88-08｜已售团变更与整团转移

| 页面中文名称 | 文件名 | 修改/新增 |
|---|---|---|
| 团期详情 | `merchant/tour/schedules-detail.html` | 增加变更影响及整团处理区 |
| 售后处理 | `merchant/sales/orders-after-sales.html` | 增加逐单变更结果 |
| 订单详情 | `merchant/sales/orders-detail.html` | 完善变更及客户决定展示 |
| 合同管理 | `merchant/sales/contracts.html` | 完善变更合同承接 |

### 页面设计指令

1. 团期详情：已有订单或成本时，修改出发日期、航班、行程及取消出发进入“变更影响”处理区，展示变更前后内容，保留原记录，不直接覆盖。
2. 变更影响处理区：列出受影响订单、旅客、资源占用、合同、已收/已退款及成本；创建或选择新团期后检查目标名额与供应条件。
3. 整团转移：按“选择订单→逐单记录客户决定→确认目标资源→查看处理结果”操作，逐单显示成功、待处理、失败及原因，部分失败允许继续处理。
4. 订单详情与售后处理：客户接受改期时展示新资源和差价；拒绝时提供取消售后；资源不足时提供替代方案或继续待处理，不能统一标全部迁移成功。
5. 合同管理：团期、金额或游客改变后提供补充协议/新版本处理，显示原合同与变更文件关联，已签文件不可直接改写。
6. 团期详情：仅航班时刻变化使用独立申请，展示成本及资源是否受影响，按配置的审批结果生效；原团有未处理订单或责任时不能直接删除。
7. 订单详情：出团后已结算的错误只提供追加调整入口，显示原结果和本次调整，不恢复无痕编辑。

4. 门店对账与分润报表：成本、优惠承担、退款或转团变化生成收益调整，展示原结果、本次增减、累计、原因及处理状态，追补和追回保留对应记录。
5. 分润报表：多层级分润列公司、层级、计算基础、比例、上限及规则版本；未生效配置不进入正式结果，供应商应付与门店收益分别计算。
6. 门店工作台：提前支用或垫资仅显示获准范围及申请处理结果，未配置规则不自动放款；未确认收益不显示可提现。
7. 分润共用脚本与报表：同一优惠承担只计一次，导出与筛选范围一致，报表保持只读，付款操作留在财务办理页面。
