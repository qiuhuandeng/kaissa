# 数据中心首批原型验收记录

日期：2026-09-13

## 一、本批范围

用户授权后，按页面字段及验收样例方案完成经营总览、订单明细、回团明细三个可操作原型。对象是财务和经营负责人使用的只读报表；上游仍是既有订单、销售归属、实际完成及财务确认流程，本批不修改它们。

| 页面 | 路径 | 当前可检查内容 |
|---|---|---|
| 经营总览 | merchant/data/performance-reports.html | 分金额视图、公司／产品组／渠道汇总、任务样例、期间趋势和数值表、未来安排 |
| 订单明细 | merchant/data/order-report-details.html | 确认期间净值、当期增减、取消／未确认筛查、全查询合计 |
| 回团明细 | merchant/data/return-report-details.html | 实际完成、财务确认资料缺口、未来安排、完成后调整空结果、演示管理月 |
| 历史方案 | merchant/data/performance-reports-legacy.html | 原经营分析完整副本，原方案二、三及产品分析也保留 |

三页均有筛选、显示字段（明细页）、排序、金额单位、实际CSV导出；明细页有分页。导出为当前视图全部查询结果及所选字段，不是当前一页，不包含总览下方补充表。

## 三、交互验收

1. 修改公司等条件后结果保持旧查询，显示尚未查询；点击查询后统一改变。导出只使用已查询条件。
2. 切换订单、变化、回团或未来安排时明确日期含义，核对后查询；未来安排另有计划日期范围。
3. 通过三页直接导航可保持共同的公司、产品、渠道、产品属性和日期范围；业务订单号及金额都是只读文字，无新增下钻或业务制单入口。
4. 默认10条分页，可改5/20/50；第一页5条、第二页1条时导出仍有全部6项。表头排序、显示字段、重置和无匹配结果均验证。
5. 财务确认视图只列完成业务的确认资料缺口；暂无确认记录，不以成交额代替收入。完成后调整无样例时显示未提供记录。
6. 桌面1440×1000与窄屏390×844检查；窄屏日期分行，报表不撑破外壳，表格内横向滚动，数值单元格无自身裁切。小屏可使用共享侧栏折叠入口，不另造导航。
7. 趋势画布有实际像素，数值表同步；未提供样例的期间显示缺失而非伪造增长率。
8. 原经营分析历史入口及产品报价页的共享导航作直接回归，不修改其业务逻辑。
