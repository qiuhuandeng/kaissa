## 本轮业务约定

公共采购增加航次供给；指定订单采购增加对应订单占用，未填写归属时保留待关联占用，不能按公共舱位再卖。物理库存按航次与舱型共用，产品、出发地和渠道额度沿用当前配置；“池内剩余”和“本使用方可申请”分别展示。

航次船票价及税费以价格日历已生效记录为准；采购成本不自动充当销售价。新采购舱型尚未确认售价时保留待报价，不生成可承诺的售价。未关联供给可以保存需求／待确认，不能直接保舱。原型会话内演示必要的库存承接，不扩展真实收付款、财务自动记账或接口。

两条主要办理结果：

- 框架合同拆单采购5间 → 审批 → 入库审核 → 关联北京产品 → 售价审批 → 从航次关联产品进入原销售预订 → 保舱1间，航次余量为4间。
