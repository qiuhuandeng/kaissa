# 88-27 领队档案、带团历史与评价实施验收

日期：2026-09-19。

## 业务位置与边界

- 领队资源：资源管理员维护同一领队的基础身份、证件及收款资料；新派团不重复建人。
- 领队详情：计调按团期反查经历与评价；计划派团、实际带团、取消、更换分别显示，只统计实际带团。
- 团期详情：计调在具体团期的“出团准备”处理派团、确认、更换、取消及实际出行；领队详情不接管日常调度。
- 三页复用独立原型记录，直接关联页以团号和领队编号承接；没有真实帐号权限、财务付款或生产接口。岗位选择仅用于演示资料可见范围，不构成生产级授权。

## 页面修改

### 领队资源 `merchant/resource/resource-tour-leaders.html`

1. 列表从同一组领队样例生成。每行详情按该领队编号打开，最近带团和实际带团次数只取实际带团；无评价显示“暂无”，证照到期显示状态，联系方式与银行账号默认脱敏。
2. “新增领队”“编辑”打开可保存的档案抽屉，维护姓名、手机号、类型、语种、可带区域、身份证号／身份依据、导游证与护照编号及有效期、开户行、银行账号和财务校验。保存后本页立即更新，重开显示本次值。
3. 新建至少有一项身份或证件依据；保存前按身份证号、导游证号、护照号检查既有档案，重复时指出已有领队并阻断新建。编辑更换证件编号或有效期时保留旧版本及更换日期，不覆盖原记录。
4. “操作岗位”演示计调默认脱敏、档案管理员维护身份与证件、财务专员维护收款资料；敏感字段在非对应岗位的抽屉只显示脱敏值且不可编辑。

### 领队详情 `merchant/resource/resource-leader-schedule.html`

1. 精简为“领队档案”“证照与培训”“带团经历”“评价记录”“费用反查”五个Tab；当前对象从领队列表带入，找不到编号时不显示其他领队资料。
2. “证照与培训”展示当前证件及更换历史；普通计调只见脱敏号码。财务收款资料在档案Tab展示，财务岗位才见完整银行资料。
3. “带团经历”可按目的地、产品、出发日期范围筛选，逐条显示来源团号、日期、产品／目的地、角色、计划或实际结果。导出按钮下载当前筛选结果的CSV文件，包含领队、团号、日期、产品、目的地、角色、结果。计划、取消和更换不计实际带团次数。
4. “评价记录”关联实际带团团号、评价时间、来源、评分及复核状态；有正常和争议样例，无评价者显示“暂无评价”，不按0分计。档案管理员可登记实际团期评价；争议内容对普通岗位隐藏，已复核评价需1—5分。

### 团期详情 `merchant/tour/schedules-detail.html`

1. “出团准备”清单的“配领队”行不再跳回团期列表，当前团期内显示领队、服务范围、时间、确认结果及实际出行。新增“领队派团与实际出行”处理区和逐次记录。
2. 派团／更换抽屉选择已有领队、服务范围、起止日期和确认结果；不可用或服务期间导游证失效者不能派团。更换领队须填写依据，保留原派团记录；已登记实际出行后不能直接覆盖派团。
3. 实际出行需日期和依据；取消派团需原因。取消与更换结果保留在记录中，重复提交相同结果不新增记录。直接关联的领队经历同步标记计划、实际、取消或更换；取消不增加实际带团次数。
