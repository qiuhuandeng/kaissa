# 88-05 定价、附加项目与佣金规则实施与验收

日期：2026-09-18。范围：`merchant/product/product-pricing.html`、`merchant/tour/schedules-detail.html`、`merchant/channel/commission_rules.html`、`merchant/approval/approvals.html`。本次只实现88-05，不继续订单采用、佣金结算或其他88编号。

## 一、页面与业务责任

- 产品经理在产品定价页维护标准销售价、建议零售价、供应商结算报价及条件规则；草稿和审批中版本不覆盖当前在售版本。
- 团控在团期详情“价格名额”维护具体团期的单房差、联运、升舱等附加项目；参考价、待报价、有效销售价分别表达。
- 渠道运营在佣金规则页限定产品、团期、渠道/门店或销售顾问范围，明确计提基础、优先级和是否叠加；退款与佣金冲减单独配置。
- 审批人在审批中心核对价格调整前后、原因、范围和申请人；未批准或已退回时继续使用原价。

## 二、完成内容

### 产品定价

1. 基础信息新增标准销售价、建议零售价、供应商结算报价、币种、价格规格、价格有效期、版本、规则优先级和冲突处理。用户复核后删除“适用团期”，团期价格在团期详情维护。
2. “保存并启用”改为“提交审批”。编辑已生效策略时生成独立审批中版本，原已生效版本保留；草稿提交也先进入审批中。
3. 用户复核后移除“价格试算”按钮、试算抽屉及相关脚本，不在定价策略列表提供模拟成交价计算。
4. 原合并控件拆为“币种”“价格规格”“价格版本”“规则优先级”四个独立字段；规格和优先级不再显示为无标签的短输入框。

### 团期详情

1. 在原“价格与名额结构”下新增附加项目表，内置单房差、联运和升舱三个差异样例。
2. 新增/编辑抽屉可维护价格状态、单价、币种、单位、数量范围、适用人群、日期和资源确认方式；有效销售价或参考价必须大于0，数量和日期现场校验。
3. 新增价格构成示例：标准10000、早鸟9500、券减300、特批0、最终应收9200；平台承担210和门店承担90只解释优惠承担，不再次抵减。
4. 保留P04-A名额释放成果及用户要求隐藏的渠道操作列。

### 佣金规则

1. 增加审批版本、审批状态、冲突优先级和同时命中处理；未明确互斥/叠加时阻止提交并提示冲突。
2. 指定对象补团期样例，新增顾问佣金页签、销售顾问政策及顾问选择表；原门店、分销商范围继续使用。
3. 冲突校验展示命中的两条政策、是否叠加及采用原因；佣金计提与退款/售后冲减分别配置。
4. 启用入口改为提交审批，页面明确批准前继续使用原版本。

### 审批中心

1. 价格申请补调整前后、最终应收、申请理由、范围、毛利和批准前当前有效价。
2. 增加盟门店无自主定价权限的已退回价格申请；只能修改重提，退回和重新审批期间均显示原价继续有效。
3. 已退回价格申请的操作改为“修改重提”，重提记录保留补充说明；批准结果仅影响批准范围，历史订单不追溯。
