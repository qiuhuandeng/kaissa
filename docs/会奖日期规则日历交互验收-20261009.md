# 会奖日期规则日历交互验收

日期：2026-10-09。本次范围为项目团批量建团中的日期规则；参照普通团期新建日期面板和日历，不调整普通团期页。

## 操作流程

计调／负责人选择客户项目并填写共同活动资料后，进入日期规则。选择周期规则或手动选日期，填写日期范围及每场天数。

周期支持每天、每周、隔周、每月固定日；隔周从开始日起每14天为一轮，前7天按所选星期安排。每月没有对应日期则跳过，不挪至月末。规则和日期输入即时更新日历、数量及提示。

日历每屏三个月，支持翻页。周期已生成日期点击排除，再点恢复；也可恢复全部。手动模式点击选择／取消，可清空已选日期。两种模式保留各自选择，外层切换直接填写不会清空活动清单。

点击“应用日期到活动清单”，将选中开始日期与每场天数转成起止日期；已有活动时确认替换。活动名称仍按前缀生成，其他值沿用共同资料，每场可以继续独立编辑。日期变更尚未应用时拦截核对旧清单，核对通过后保存草稿。

## 产品判断与边界

原团期页的节假日集合是演示日期，不把这些数据复制为真实排期规则。未配置正式日历前提供手动排除；没有新增真实政策、成交、应收或财务动作。每场天数1—366、单次200场限制保持，结束日期亦校验项目／本人分工期间。
