# 外采预付款逐明细退回第三步实施验收

> 日期：2026-09-29  
> 范围：预付管理发起、供应商提交退款凭据、资金核对实际到账  
> 结论：第3步原型完成，外采供应商对账、付款与退回三步工作线收口

## 一、业务位置与职责

- 上游是已审批并实际付款成功的外采预付款明细；未付款成功的安排不能要求供应商退款。
- 应付人员在“预付管理”按原付款明细发起退回；申请只占用可退金额。
- 供应商管理员在原“供应商对账”页面的独立“预付款退回”视图提交退款交易号、日期和凭据，不进入我方资金操作。
- 资金人员在“付款退回”按实际银行入账流水核对，可分次到账；只有到账核对才减少预付余额和实际净支付。
- 原付款单及成功付款金额始终保留，不用修改原付款金额模拟退款。

## 三、金额和状态验收

示例预付单有五笔付款明细，其中两笔可退、1笔付款中、1笔已全额冲抵、1笔已全额退回：

1. 两笔成功付款分别申请退回5,000元和8,000元，形成13,000元退回申请。
2. 申请后预付余额仍为53,000元，只把13,000元列为处理中。
3. 供应商上传13,000元退款凭据后，实际到账仍为0，预付余额仍为53,000元。
4. 资金先核对6,000元到账，状态为“部分到账”，预付余额降至47,000元。
5. 再核对7,000元到账，状态为“已到账”，预付余额降至40,000元。
6. 原成功付款合计98,000元不改写；退款全部到账后实际净支付为77,000元。

## 四、异常验收

- 未付款成功、已全额冲抵、已全额退回、已被其他申请占用或超可退金额均不能申请。
- 预付申请未通过不能要求供应商退回。
- 无退款凭据不能核对到账；重复流水、错采购公司、错供应商、错币种或分配超过申请金额均不能确认。
- 已开发票的快速退回先拦截，提示按财务要求完成作废或红字处理；外币退款汇率规则继续待确认。
- 申请、凭据、部分到账均保留处理历史，不删除原付款。
