# 销售移动小程序首条业务原型实施验收

日期：2026-09-28。执行依据为用户“执行”及[页面与操作流程设计](销售移动小程序页面与操作流程设计-20260928.md)第九节的首条国内参团游原型。本次以 merchant 销售岗位和原业务流程独立实施，文件位于新建 `sales/`，四个主入口为工作台、产品、客户、订单。

## 2026-09-28 追加：长页面无法滚动修复

用户指出产品详情及多个页面下方内容不可见。原因是共享后台样式给body设置100%高度和禁止溢出，而本端只覆盖了横向设置，仍继承纵向禁止滚动。首轮验收的宽度及业务断言没有验证真实纵向输入，不能作为页面内容可达的证据。

本轮仅调整销售、游客两页的文档标识和本端CSS：由文档承担纵向滚动，页面随内容增高；保留固定导航／操作栏并为末项内容留出底部安全区域；长合同弹窗可以独立滚动。共享后台样式、业务脚本、业务模型及现有演示记录不变。

[滚动专项脚本](../tests/sales-workbench-scroll-browser.cjs)已通过桌面980×874及手机320×568、390×844、430×740的62次页面场景、453个检查点，运行时异常0。使用浏览器真实滚轮事件、模拟手机触摸滑动，检查末项内容位于底栏上方、返回栏可点击，并以实际指针点击保存预订草稿、暂存游客资料及本人签署；也覆盖合同弹窗滚动、关闭后继续滚动及换页回顶部。手机触摸为Chrome模拟，未替代真机软键盘验收。

产品页实测可滚动范围分别为桌面518px、390宽520px、320宽814px、430宽604px，均实际到达末尾。记录及底部截图见[滚动验收目录](../sales/screenshots/scroll)。本缺陷已修复，刷新页面即可使用；后续功能断点仍为S15，不在本轮扩展。

## 一、本次交付和上下游

主要使用者为门店销售顾问，处理本人客户、意向和订单。产品、日期价格、余位及确认条件来自已发布的可售产品；销售接待咨询、核对客户需求并预订。订单后的资金、合同、资料分别办理：财务复核认款，合同经办审核及我方签章，计调确认资源和发布出团资料。销售查看各项结果，游客只办理本单授权给本人的事项。

本次交付为可操作 HTML 手机原型。身份、付款、合同平台、财务与计调结果使用明确演示资料；数据仅在同一浏览器的本端销售页和游客页间共享。未接入真实小程序、短信、支付、电子合同或后台，不向 merchant、财务及其他移动端自动回写。

| 入口 | 本次可办理内容 | 范围说明 |
|---|---|---|
| 工作台 | 个人工作身份、咨询接待、今日回访、退回事项、资料待核、继续草稿、本人申请 | 不展示其他顾问业绩及财务执行动作 |
| 产品 | 可售产品、目的地／日期／余位／预算筛选，日期确认方式，行程费用退改，产品介绍及具体报价分享 | 具体报价保留日期、人数、金额、有效期；指定客户推荐核对身份 |
| 客户 | 查重建档、本人档案、常用同行人、本次意向、跟进与回访、关闭／恢复、关联订单 | 咨询、意向及提交订单分别留来源，不因浏览或咨询记为成交 |
| 预订 | 选择日期人数→核对客户游客→核费用条件；保存恢复草稿、确认／待确认／预留／占位 | 即时确认与二次确认分开；未定条件不自动生成保留期限或放行付款 |
| 订单 | 本人订单检索及状态筛选、金额、资金结果、合同、逐人资料、出团通知与记录 | 已确认收款、待复核认款、未知付款分别展示；预计金额不冒充确认应收 |
| 认款 | 原退回申请补关系和凭据后重提、新认款、查看结果 | 待复核不计实收；限制超额与原流水重复认款，保留原编号 |
| 合同 | 资料门槛、示例文本和附件、审核／补正、发起签署、受理未知查询、逐人结果和我方签章 | 当前为一份国内成人合同；其他合同拆分、监护及授权代签尚未制作 |
| 游客 | 产品推荐、咨询、本单摘要、定金／尾款、本人签署、本人资料暂存提交及退回补充、已发布出团通知 | 第一位成年游客为本样例付款联系人；其他成人无付款入口及他人完整证件 |
| 演示场景 | 付款成功／失败／结果未知、合同受理未知、财务认款、合同审核／签章、计调资源和通知结果 | 在员工头像→工作身份单列场景面板，不能解读为销售实际有这些执行权限 |

销售页路由承载 S01—S14、S17、S18 的本代表场景；游客页承载 G01—G07。S15服务与金额变更、S16售后没有在本轮标为完成，不能把旧后台已有页面当作本端已交付。

初始化退回认款订单同为总额12,000元、已收4,000元；8,000元尾款认款补充“配偶代付”后仍为待复核，原申请 RK-001 不变。财务示例复核通过才增加已确认收款。合同一位成人已签不代表另一位已签，两人签完仍需我方签章。

本次金额、保留期限、人均定金和资源回复均为指定团期演示条款，不代表统一公司政策。12月9日样例保留及付款条件未定，只可草稿或待确认，不能提前付款或确认订单。未成年人可表达报价及名单，但监护签署尚未实施，合同门槛会明确阻断。
