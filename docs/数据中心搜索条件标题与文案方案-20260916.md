## 一、范围与判断原则

已检查17个菜单、93个Tab，展开更多筛选，核对日期、月份、数字、文本及下拉条件。浏览器无脚本错误。证据：outputs/20260916-filter-label-policy/fields.json。覆盖默认进入及展开状态，不把这次检查当作所有联动组合的穷尽验收。

使用者为公司/集团财务、经营分析人员及授权负责人。筛选负责确定业务范围、时间与数据版本，结果区负责查看已查询内容；标题调整不改变上游业务、统计口径、默认范围、排序或财务计算。

判断必须同时看“默认值”和“选中具体值以后”。补成全部销售公司后，选中A公司仍可能与产品经营公司混淆，所以仅补默认文案不能解决所有问题。

## 二、必须保留左侧标题

| 类型 | 建议左侧标题及示例 | 原因 |
|---|---|---|
| 业务日期区间 | 订单确认日期、实际完成日期、业务完成日期、采购确认日期、变动日期等，后接开始日期 至 结束日期 | 裸日期无法表达按什么事实选数据；一组区间共用一个标题 |
| 独立截止日 | 资料截止、余额截止、收付截止、票款余额日、资金基准日 | 可能同时出现相同日期，但分别决定纳入资料、余额或期初资金，不能合并 |
| 月份、年度、适用日 | 会计期间、执行月份、任务年度、版本适用日期、规则适用日期 | 日期格式相同但业务含义不同；起止月份用一个区间标题 |
| 版本 | 数据版本、损益版本、预算版本、任务版本、预览版本 | V1、已发布V1、PUB01本身不能解释是哪种版本 |
| 公司角色 | 销售公司、产品经营公司、核算公司、资金公司、成本承担公司、采购公司、结算公司 | 同一家A公司可能承担多个角色，不应统一叫公司 |
| 组织及人员角色 | 销售事业部、销售部门、产品事业部、产品经营组、销售部门领导、产品部门领导、产品负责人、顾问等 | 选中具体组织或姓名后不能只靠名称判断角色 |
| 易混淆的归属维度 | 地理目的地分区、管理目的地分区、预算区域；同页有主成交渠道与获客来源时分别标明 | 同一名称可能出现在不同分类中 |
| 控制分析方式的条件 | 分析责任、汇总方式、统计层级、责任层级、结构分类、金额列组、统计粒度、任务指标、预算指标、比较期间 | 销售公司可能是一个筛选对象，也可能是汇总方式；本期业绩是列组，不是日期 |
| 有作用对象的数值 | 长期占用天数：90 天 | 不能只显示90；保留单位，不改阈值含义 |
| 权限范围 | 查看角色、公司范围、部门范围、门店范围、预览公司/部门/门店 | 授权全部不是全集团全部；角色不能仅由具体名字推断 |
| 同页并列的易混淆编号输入 | 订单号与来源订单号、多个账户/确认/分配编号同时独立出现时分别标明 | 输入后占位文字消失，不能再辨认各输入值的用途 |

日期依据已由紧邻区间的下拉框清晰表达时，可让这一个带左侧标题的下拉框承担日期语义，不在后面重复同名标题。单独资料截止必须保留。

## 三、可以不常驻标题，但文案必须自解释

| 条件 | 建议表达 | 边界 |
|---|---|---|
| 简单业务分类 | 全部产品类型、全部供应关系、全部旅游范围、全部成本项目、全部采购类别、全部采购用途 | 具体选项应能识别，如酒店、交通、自营组织；与邻近字段重名时再加左侧标题 |
| 完整状态 | 全部订单状态、全部结算状态、全部资料情况、全部核对结果 | 有效等过于泛化的具体选项改成有效订单等；不改变选项取值 |
| 单一综合搜索 | 输入团号、名称或结算单号；输入供应商、采购单或账单 | 不新增长左侧标签，保留明确占位文案与控件名称提示 |
| 金额单位 | 人民币·万元；原币·元；原币·万元 | 不同币种条件与金额单位条件不能混成一个；普通元/万元在并列币种控件时可保留，但必须能辨认其为单位 |
| 统计快捷范围 | 自选期间、所选7日区间 | 不把固定历史7日误改为近7日；具体日期仍在旁边显示 |
| 结果区汇总/明细切换 | 当前已确认的固定160px下拉 | 继续隐藏显示层级/查看内容前缀，有显示字段时置于其前，无按钮时靠右；本次不恢复结果工具栏标签 |

若某个具体分类选项无法独立说明用途，应转入左侧标题方案，不能仅因默认选项加了全部就认定不需要标题。

## 六、布局规则

1. 标签与其控件组成不可拆开的横向单元；空间不足时整组换行，不让标题单独留在上一行。
2. 日期区间整组排列；常规宽度不足时整组换行，极窄屏需明确适配，不压缩到看不清日期。
3. 条件间及操作按钮前维持12px间距，更多筛选仍跟在最后一个常用条件后。
4. 左侧标签用内容宽度，不给所有标签设置同一个过宽宽度。
5. 搜索条件控件不套用结果区固定160px规则；日期、编号、长组织名按原有类型宽度核验。
6. 必须标题在默认、选中具体值、重置、切换日期依据后都可见且正确；无标题控件仍保留可访问名称。

## 七、确认后实施边界与验收
