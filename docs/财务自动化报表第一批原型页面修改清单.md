# 财务自动化报表第一批原型页面修改清单

> 版本：第一版，2026-09-06  
> 本批主题：订单与实际回团的数据埋点表达  
> 当前用途：确定原型页面需要表达的功能、使用流程、字段、状态和下钻方向；不要求模拟数据跨页面真实汇总，不代表正式系统已经完成数据自动化。

## 一、本批要解决什么

财务五类报表有两个最基础的时间入口：订单确认生效时间和实际回团或服务完成日期。当前原型中，订单有创建页面但缺少完整的发生时归属，团期“标记已回团”又只改变状态，没有形成可核对的实际完成记录。

第一批只完成以下业务结果：

1. 销售顾问知道订单在哪个动作创建、何时正式确认、哪些订单才进入订单口径业绩。
2. 订单确认前能够核对产品、团期、销售组织、渠道、门店、人员和预算区域等发生时归属。
3. 销售中心继续作为客户订单唯一主入口；履约中心只从团期执行角度查看同一订单。
4. 计调或团控通过“确认回团”形成实际回团日期、确认人、确认时间和依据，计划日期不被覆盖。
5. 已回团业务可以继续进入成本整理和业务结算，但确认回团不直接等于结算、收入确认或财务入账。
6. 订单和履约页面不再用固定比例或无来源金额冒充实际成本、应付、已付或收入。

## 二、首批页面范围

旧蓝图只列了产品预订页，但代码核对确认：`sales-product-quote.html`负责选择产品和团期，真正提交订单的是`booking.html`。原计划首批范围为9个页面；2026-09-12用户确认团期订单列表和详情是有意独立设置的入口，本批不修改这两页，当前范围调整为7个页面。

| 顺序 | 功能模块 | 页面 | 主要使用角色 | 本批定位 | 处理级别 |
|---|---|---|---|---|---|
| A1 | 销售中心 / 产品预订 | `merchant/sales/sales-product-quote.html` | 销售顾问 | 选择产品、方案和具体团期，把明确的销售对象带入新建订单 | 优化 |
| A2 | 销售中心 / 新建订单 | `merchant/sales/booking.html` | 销售顾问、门店销售 | 形成客户订单、订单时间、销售内容和发生时归属 | 必须改 |
| A3 | 销售中心 / 订单管理 | `merchant/sales/orders.html` | 销售顾问、销售主管 | 客户订单唯一列表入口，按订单主状态判断和处理 | 必须改 |
| A4 | 销售中心 / 订单详情 | `merchant/sales/orders-detail.html` | 销售顾问、销售主管、财务只读核对 | 查看订单销售事实、发生时归属、变化和下游承接 | 必须改 |
| B1 | 履约中心 / 团期订单 | `merchant/tour/schedule-orders.html` | 计调、团控 | 用户有意保留的独立团期订单入口 | 保留，不修改 |

| C1 | 履约中心 / 团期管控 | `merchant/tour/schedules.html` | 计调、团控 | 管理团期主状态，并通过抽屉确认实际回团 | 必须改 |

本批不修改产品编辑、组织资料、渠道资料、收退款、应付付款、业务结算和财务报表页面。它们分别进入后续模块批次。本批只在订单确认摘要中表达这些资料的发生时结果和未来来源，不把资料维护功能塞进订单页面。

| 历史迁移订单 | 选择历史来源场景 | 来源系统、原订单号和导入批次可核对 | 要求普通销售填写防重复标识 |
| 履约查看订单 | 销售订单详情 → 关联团期 → 团期订单履约详情 | 相同订单号、当前团期销售内容、名单资料和资源状态 | 在履约页修改销售归属、收款或取消客户订单 |
| 正常回团 | 团期出团中 → 确认回团 | 实际回团日期、确认人、确认时间和完成依据 | 点击一次直接变状态而无确认记录 |
| 延期回团 | 计划回团日之后确认 | 计划日期保持不变，显示实际日期、延期天数和原因 | 用实际日期覆盖计划日期 |
| 跨年回团 | 上年订单、上年出团、本年实际回团 | 订单日期与实际回团日期分别显示，可进入两种报表口径 | 把订单年份改成本年 |
| 回团更正 | 已回团 → 更正回团 | 原日期、新日期、更正原因、人员和时间均可看 | 覆盖原记录后无法追溯 |
| 成本未确认 | 已回团 → 团期成本 | 预估成本、实际成本、供应商结算、应付和已付分别显示状态 | 按订单金额或成本比例自动生成正式收入、已付或毛利 |

## 十一、第一批完成后的下一步

完成1A至1E页面改造并逐场景走查后，再生成第二批清单。第二批优先处理组织人员、渠道门店和预算区域资料，以及收款、应收、退款和转款的金额边界；随后才进入成本应付付款、业务结算收入确认和五类财务报表页面。
