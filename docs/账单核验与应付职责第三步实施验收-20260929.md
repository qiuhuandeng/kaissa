# 账单核验与应付职责：第三步实施验收

日期：2026年9月29日。按用户继续“执行”完成成本应付方案第3步，收口成付01、02及07的原应付承接。前两步付款复核、付款管理两页签、预付管理两页签和逐实际付款退回保持；原报表8批不重开。

## 一、菜单、角色和上下游

| 页面 | 主要使用者与任务 | 来源及办理结果 |
|---|---|---|
| 履约供应商对账 | 计调确认服务、数量、价格和差异，供应商确认账单版本 | 业务结论及账单材料交财务；财务不代替业务协商加价或扣减 |
| 财务账单核验 | 应付财务核对公司、供应商、币种、费用范围、业务确认及材料，排除重复报账 | 保留原账单和确认依据；通过后补原应付材料，缺失或争议退回原经办；不再次生成应付 |
| 财务应付管理 | 应付财务确认欠款、核对原付款抵清及预付冲抵、处理已确认业务调整和退回对应的余额 | 来源为有效成本、最终账单或具备确认条件的合同债务依据；同笔费用确认一次，后续保留调整记录 |
| 财务付款复核 | 复核业务提交的付款依据、金额、公司和账户，送既有审批或退补 | 不重复发起业务请款，不把最终对账作为所有成本付款的前置 |
| 财务付款管理 | 资金岗在付款执行、付款退回两个页签办理资金收支及实际到账 | 原付款、退回申请、到账分开；实际到账交应付或预付核对，核算岗另行办理凭证 |
| 财务预付管理 | 核对预付余额、冲抵及全部退回历史 | 未用预付退回按每笔原成功付款分别申请，已冲抵、已退及在途占用不能再退 |

账单核验保留补录专项材料、核验通过、退回业务、关闭已明确原单的重复资料。删除原财务“补差、部分认可、供应商承担”等定价动作。专项补录只能引用已有费用，不能用财务补录绕过业务确认。

应付列表按主流程状态显示“确认应付”或“详情”。已确认应付不再出现重复保存同一版本核对的按钮。来源经办、业务确认依据、原付款、抵清分配、申请在途、原对账及其版本均在详情核对。

## 二、金额和退回规则

应付是已确认需要支付给供应商的欠款。抵清表示已将付款或预付用于清偿这笔欠款。付款总额和抵清本应付的金额分别保留，不能混用。

当前确认金额由原应付加有效调整形成；未结清扣除预付冲抵和有效付款抵清，再按已核对的退回恢复对应抵清。可申请还要扣除审批中、待付款、付款中的占用，最低为零。多付金额单列为多付应退。

| 验收情形 | 结果 |
|---|---|
| 10万元应付，预付冲抵3万元、付款抵清5万元、申请在途8千元 | 确认后未结清2万元，可申请1.2万元；原付款和冲抵不被清零，也不把待付恢复为10万元 |
| 业务8万元、供应商账单8.2万元，差异未确认 | 财务核验被拦截，可退回计调补依据；保留两方金额及2千元差异 |
| 供应商账单52.8万元，业务已确认优惠500元 | 核验后沿用52.75万元欠款依据，不能再扣一次500元 |
| 原欠款10万元、实付12万元，最终业务确认9万元 | 先登记已确认的减费1万元，形成多付应退3万元；实际到账3万元后结清，确认额仍9万元，原两笔实付7万及5万元保留 |
| 已成功付款被银行退回1万元，原欠款仍需支付 | 原确认额10万元不变，未结清由2万增为3万元；扣8千元在途后可申请2.2万元 |
| 未抵清应付的重复付款退回或未用预付退回 | 不增加应付，不改变已确认费用；未用预付在预付管理核对余额 |
| 原款未匹配、没有真实到账、公司或币种不符、原责任未确认 | 不能改变应付余额，交资金或业务核对 |
| 外币原款分配、旧抵清或占用依据缺失 | 未结清显示待核对，可申请不放行；不把人民币冲抵直接扣外币应付，不用倒算金额补造明细 |

原始样例的公司、供应商不一致时分开保留来源，不因为同为邮轮或铺位就强挂一笔应付。未知业务核对金额显示待核对，不显示成零元。正式确认时点、会计科目、入账期间、红字发票和外币差额政策仍待财务确认。
