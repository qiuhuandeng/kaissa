# 单团会奖菜单归集

日期：2026-10-24。依据：用户明确确认产品中心、履约中心、单团会奖三个模块的菜单结构，并要求修改菜单和相关文档；随后明确原“产品管理”改名“自营产品”，单团会奖排在履约中心上方。

## 本次范围与业务承接

销售和项目负责人从客户委托建立单团项目，计调在项目团控安排具体会议或出行，采购经办在项目采购维护公共、跨团及单团采购。三个既有入口集中归入“单团会奖”，一级短名为“单团”，位于产品中心之后、履约中心之前。

产品中心继续管理可复用产品、外采来源及销售政策；履约中心继续承接通用团期、团期订单、团期结算、付款申请、签证办理和供应商对账。单团、邮轮与其他类型共用原结算；销售订单、合同、收付款、审批及财务核算的页面和职责不变。
