# 资金日报与月度执行新增验收

2026-09-15｜整体方案6.12｜原型交付

## 一、角色和业务位置

公司出纳、公司财务及集团资金人员，日报用于核对每天期初、分类收支、期末及可用；月度执行用于观察整月各类资金的实际收付。上游是已确认实际流水、公司账户、期初历史、资金分类依据及带日期受限资料；下游资金办理仍在办理页面。报表只读，不新增付款、调拨、审批或跨页面回写。

## 四、边界和下一步

这是原型查询验收，不是实账验收。正式资金用途及分类生效记录、完整银行流水、每日受限历史仍未接入。日报没有将旧账户视图中的无日期受限金额扩展为每天数值；因此未提供当日资料时可用显示未提供。受限有/无依据及冲突场景在独立计算测试中验证，默认页面没有伪造历史资料。

月度执行缺少历史时，已列的可识别流水只表示已知组成，另有范围完整性缺口行，不能当作完整全公司结果。不同币种不相加，不推集团资金控制或法定现金流量分类。

唯一下一步：按整体方案6.13重组票款核对四Tab（已收未开、已开未收、已付未收票、已收票未付）；其他核算/管理多表主题及经营补充继续保留待办。
