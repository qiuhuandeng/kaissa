# 资金账户余额与收支重组验收

2026-09-15｜整体方案6.12本次步骤｜原型验收

## 一、角色与业务位置

集团资金人员、公司财务先查同截止日各实际账户有多少钱、多少受限，再按实际发生日期核对银行或支付商户流水。上游为已确认资金流水、账户期初和受限资料；下游为资金汇总和计划分析。本页只读，不发起付款或回写业务单据。客户预收责任不等同银行账户。

## 四、限制与唯一下一步

当前为示例资料原型，未接正式账户、银行对账单及动态受限历史。受限金额沿用来源资料，尚不能证明任意历史截止日受限准确；同日流水沿来源顺序，不宣称银行精确日内余额。冲突资料使账户过程余额未知，单笔金额仍展示来源记录，正式上线须先解决来源冲突。银行实账核对尚未交付，财务政策仍待确认。

下一步只推进资金分析“收支汇总、资金计划”两个主题；日报、月度执行及其他10个多表主题按整体方案后续推进。原8批、36验收点、6场景和并行计划/门店工作线保持。
