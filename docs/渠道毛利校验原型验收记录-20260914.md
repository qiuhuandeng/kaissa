# 渠道毛利校验原型验收记录

日期：2026-09-14。阶段4第7小批前半批。只验收分析原型，不是正式财务核平或生产服务验收。

## 一、页面与边界

入口：数据中心 → 经营报表 → 渠道经营 → 渠道毛利校验。文件为 `merchant/data/channel-reports.html`，未新增菜单或独立报表页，可直接打开本地HTML。上游产品、订单、履约和财务负责业务事实及金额确认，财务分析和渠道负责人在本页只读核对；没有审批、收付、结算、下钻或跨页面回写。

本次依据四份控制文档及《渠道毛利校验字段来源与验收任务卡-20260914》。共同订单资料只列实际缺口，独立算例不加入共同经营金额。未改团期订单、订单详情、团期成本、渠道结算、佣金政策和其他报表金额。并行门店文档及未提交修改保持原样。

## 二、交付内容

- 在原四个渠道视图旁增加第五视图，独立保留筛选、分页和显示字段；返回原视图不改变其已查金额与口径。
- 默认10列，按订单核对。一单多项归到同一订单；主表缺口最多三行，完整原因在基础确认表及导出保留。
- 日期依据可选订单确认、实际完成或结算确认，无日期不兜底。共同资料只提供2026-05-07截止，不支持用旧查询日伪装历史金额；算例按各确认、生效时间判断影响。
- 基础及更多筛选覆盖公司、渠道、订单、团号、产品归属、门店、中心、组、顾问、经营分类、供应关系、散拼单团、来源、费用资料、币种和单位。筛选是保留符合条件的整单核对范围，不拆掉混合订单中的其他销售内容。
- 三张直接展开的全量依据表：销售内容及基础确认、升舱优惠与费用分配、还原影响及原记录调整。可选原基础、费用、还原金额、精度及确认和组织字段。
- 导出包含已查询范围的全部订单、所选字段、三张依据表、完整缺口、资料截止、金额单位和未批准规则。未查询条件、当前分页不改变导出范围。
- 未启用正式比较方式、阈值差距或符合/不符合判断；已正式校验始终为0单，齐全算例的合计比率只按同币种、同金额口径、同规则的正分母子集计算。

## 三、计算验收

`tests/channel-margin.test.cjs` 新增16组，对应任务卡C01至C16的计算部分；C15/C16的浏览器部分另列于下节。

| 场景 | 实测结果 |
|---|---|
| 共同范围及原业绩 | 默认5单、6项、54,000元，无确认收入成本，不出毛利；原四视图订单54,000、实际完成56,000、年累计59,000元保持 |
| 升舱优惠 | 独立算例10,400−1,000＋600＝10,000，扣减10,000−1,000＝9,000，毛利1,000／10%；仍为规则待确认 |
| 多承担方 | 优惠600＝本公司300＋门店部门200＋外部平台100；演示仅加回本公司300，不将总优惠当本公司承担 |
| 补偿与返点 | 已含基础的补偿及返点还原影响为0；是否已含不明时不算完整结果 |
| 费用分配 | 原费用300分100与200，已含分配额不重复扣减；仅分250时保留未分50并阻止完整结果；未确认不生效 |
| 范围与混合 | 明确非适用、内部供应未确认、缺分类及自营外采混合分开；混合订单成交仍保留10,000，不删除外采项来判整单 |
| 阈值及舍入 | 9.99%、10%、10.01%的等于／不低于／严格高于测试预期分别验证，但不进入正式页面判断；9.9999%显示10.00%不改变未舍入值 |
| 零值与缺数 | 未知非0，负毛利如实列出，零或负分母不算率；齐全子集不伪装全范围 |
| 合计 | 两单1,000／10,000与300／1,000，合计1,300／11,000＝11.81818%，不平均为20% |
| 重复与冲突 | 同源同号完全重复只计一次；冲突基础金额不任取首条出结果，错误公司/币种分配、超额或重复分配阻止完整校验 |
| 跨期与调整 | 上月订单可按本月实际完成查询；生效减项计一次，退款支付不二次冲减，截止后调整不进入；原记录不符或调整早于基础确认显示异常 |
| 组织与多项 | A销售B产品独立筛选；同名顾问保留公司及发生时身份；多项/多次完成不重复整单，不兼容币种、税额和规则不合成比率 |

本轮合计140项计算及规则测试通过，包括原124项回归。独立数据集共有20张算例订单，默认订单确认期间命中19张，跨期订单CM17须按实际完成、结算确认或扩大确认期间查询。不同状态为刻意保留的核对场景，不是随机错误。
