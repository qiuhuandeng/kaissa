## 一、本次结论

在现有“数据中心 → 经营报表 → 渠道经营”内增加第五个视图“渠道毛利校验”，不新建一级菜单，不改现有四个业绩视图。财务先看需要核对的订单及缺失依据，再直接查完整费用明细和导出。

这一结果是渠道考核核对，不等于团期毛利、渠道佣金、门店分润或员工奖金。不能把整团利润按成交占比分给渠道，也不能拿外采门店“毛利10%平台留存”的示例当作自营散拼的毛利率规则。

## 四、统计对象与金额关系

### 1. 订单为核对单位，费用逐项保留

默认一行是一张来源明确的订单在同一校验范围内的结果。订单中可单独确定产品、团期和金额的一项销售内容，是费用归属与核数的最细业务单位。主表不按优惠或成本条数展开重复整单金额。

一单含多个产品、团期或多种适用范围时，先分别保留销售内容和费用分配；统一规则、币种、金额口径且全部所需资料齐全后，才可形成对应范围的订单结果。含自营与外采的混合订单，在适用规则未批准前显示“适用范围待确认”，不能删除外采部分后冒充整单通过。

一个来源费用分到多个销售内容时，已分配合计加未分配金额必须等于确认原额。分配未完成、跨公司/币种错误、同号冲突均阻止受影响订单出完整毛利；仍展示已知数据。重复同一来源记录不能再次生效，冲回和更正必须保留原记录。

### 2. 先讲金额含义，再谈公式

“还原”仅指为考核比较而按批准规则调整分析金额，不改客户成交、供应商应付或会计结果。

| 金额 | 必须记录和区分 | 禁止替代 |
|---|---|---|
| 原成交与原校验基础 | 客户成交参考；另列经确认的原校验收入、原校验扣减额及其定义。扣减额指该考核要求扣除的成本或结算金额，具体范围待财务确认 | 原校验收入不默认等于成交、实收或会计收入；原校验扣减额不默认等于整团成本或渠道净回款 |
| 升舱 | 客户升舱收费、对应确认成本、承担方、所归订单内容、是否已含于原基础 | 不按收费反推成本，不强设平进平出；剔除收费与成本必须分别有依据 |
| 优惠 | 每项原优惠、承担公司/部门或外部单位、各方金额、第三方补偿、确认状态、对原基础的实际影响 | 全部优惠不能都算本公司承担，也不能全部加回；已计补偿不能再加一次 |
| 平台费与佣金 | 平台使用费、平台服务费、外部渠道佣金分别列，保留账单、费率或固定额依据、订单分配及是否已含于原基础 | 相似名称不合并；净回款不是收入，不因账单扣过佣金而重复扣成本 |
| 返点 | 预计、确认、分配及已进入成本的影响分开 | 供应商总返点不复制到每单，不与已冲减成本记录重复计算 |
| 调整 | 原记录、本次生效差额、原业务期间及确认日期、依据、所影响收入或扣减额 | 待审批不生效，退款支付不再次扣已生效成交减项，不覆盖原记录 |

经批准规则才能确定：还原后校验收入＝原校验收入＋逐项收入还原影响；还原后校验扣减额＝原校验扣减额＋逐项扣减额还原影响；校验毛利＝前者减后者。毛利率的分母是否采用还原后校验收入，仍需财务明确，不能仅凭“毛利率”三个字补齐。

同一费用的原始金额与本次还原影响分开显示，已包含、未包含、无法判断三种情况分别记录。无法判断不按0处理。含税与不含税、原币与折算金额不能混算；税额或汇率来源缺失不推算。负毛利如实列示；分母为0或负数时不直接输出达标结论，特殊考核处理待确认。

### 3. 结果、汇总和导出

核对结果只用一个主状态：不适用、适用范围待确认、资料待补齐、数据异常、规则待确认；正式规则及资料齐全后才允许符合、不符合。判断先查适用事实，再查重复/金额冲突，再查资料齐全，再查有效批准规则，最后比较。其他缺口不因主状态优先级而隐藏，直接列缺口原因。

无适用订单时显示0单，不显示100%通过；没有批准规则时，已正式校验0单，不能把空结果当全通过。缺数订单保留在总范围中；仅齐全子集可列明确标注的合计。汇总率只能用同范围、同规则、同币种的合计分子除以合计分母，不能平均各单百分比；汇总达标也不能覆盖其中不达标订单。

导出包含已查询条件、期间及截止、单位、资料性质、规则状态/版本、全量主表及三张依据表。已知合计和缺失条数分开，未查询条件不污染当前结果及导出，分页不截断导出。分析不创建优惠审批、佣金、成本、财务凭证或奖金。

| 优惠与费用 | 总部、销售门店、渠道、供应商及平台优惠各如何处理；补偿、平台使用费/服务费、佣金、返点是否已含且是否进入校验 | 财务和渠道负责人提供多承担方、已含费用、退款反向调整算例及原单据 |
| 10%规则 | 等于、不低于还是严格高于；比较前如何保留精度；是否允许误差；零或负分母如何处理 | 财务负责人确认9.99%、10.00%、10.01%及舍入临界值的预期结论 |
| 周报与历史 | 按哪个业务日期筛订单，费用看哪个截止；规则生效日以订单、回团还是结算匹配；后补成本是否重述历史 | 财务分析及结算负责人给出周界、跨期调整和规则换版样例 |
| 主体、税额与可见范围 | 管理考核与法定核算如何区分；使用何种含税口径和汇率；谁能看其他公司或门店成本 | 财务/税务及权限负责人提供金额口径和授权范围，复用既有相关决策 |

RPT-06、08、10、11、12、14、15中共同规则继续复用，不另设第二份相反结论。拿不到正式规则时可以制作核对原型，但不得启用正式达标判断；后续“执行”仅授权原型制作，不代替上述答复。

## 八、独立算例与后续验收

下列数值仅用于演示核数和测试，不来自财务真实订单，不混入共同经营业绩。唯一演示约定：以给定校验收入作分母，剔除已含升舱收费与成本、加回已明确计入收入的本公司优惠；不代表正式还原公式。

算例一：原校验收入10,400元，原校验扣减额10,000元；已含升舱收费1,000元、成本1,000元及本公司优惠600元。演示还原收入为10,400−1,000＋600＝10,000元，扣减额为10,000−1,000＝9,000元，毛利1,000元、比率10%。正式核对结果仍为规则待确认，不能默认通过。

算例二：同一费用确认300元，分配订单甲100元、乙200元，合计300元；若甲的扣减额9,000元已经含100元，本次不再扣100元。若只分配250元，另50元待分配，不自动补给剩余订单；原单300元不在主表合计两次。

| 验收号 | 场景 | 必须得到的结果 |
|---|---|---|
| C01 | 无升舱、无优惠且有明确无费用依据 | 原金额与还原金额相等；无费用可以是0，没有依据不能冒充无费用 |
| C02 | 算例一含升舱与优惠 | 演示10,000/9,000/1,000/10%可核平；升舱仅收费无成本时不出完整结果 |
| C03 | 同一优惠600元拆本公司300、门店200、平台100 | 分担合计600；只把规则允许且已计入基础的金额还原，不把三方全部当本公司 |
| C04 | 渠道补偿已含原收入、供应商折让已含成本 | 不重复补收入或减成本；影响方向不明时待确认 |
| C05 | 算例二平台费一单已含、多订单分配未完 | 不重复扣100，不把原额300复制每单；未分配50保留且阻止受影响结果完整 |
| C06 | 自营散拼、外采、内部供应、混合订单、分类缺失 | 已明确不适用者单列，其他按适用依据；不得把“跟团游”一律判自营散拼 |
| C07 | 分子999、1000、1001，分母均10,000 | 分别9.99%、10%、10.01%；等于模式仅中间满足，不低于模式后两者满足，严格高于仅最后满足。三模式是测试预期，不是正式任选开关 |
| C08 | 分子999.99，分母10,000，展示两位小数 | 展示可能为10.00%，底层9.9999%不因展示而视为达到10%；正式容差待批准 |
| C09 | 基础或分配金额未知、真实0、负毛利、0或负分母 | 未知非0；负毛利保留；无有效分母不算比率或判通过；缺失金额不合计成完整总额 |
| C10 | 两单分子1000/300，分母10,000/1000 | 齐全同规则子集合计1300/11,000＝11.81818%，不平均成20%；按单比较不能被合计掩盖 |
| C11 | 同源记录重复、来源同号金额冲突、跨公司或币种误分配 | 重复不重计，冲突显示异常不任取首条；不同来源号相同不未经核对合并 |
| C12 | 上月订单本月完成、截止后补成本、退款支付晚于减项 | 三类日期独立命中；截止后不进入当时结果；生效减项只算一次；原记录及调整均保留 |
| C13 | A公司销售B公司产品、同名门店/员工、历史调组 | 对客成交不倍增；销售与产品分别筛选，历史归属保留，不用当前任职覆盖 |
| C14 | 同单多项、多次完成、不同规则/税额/币种、未确认分配 | 不重复整单基础；不跨不兼容范围合成一个率或整单通过；未确认不视为0 |
| C15 | 待查询、分页、选列、空表、完整导出 | 文件只含已查全量结果及依据、缺数、规则和单位；空范围不是全部达标 |
| C16 | 本地HTML、菜单进入、桌面1440与窄屏390、原四视图回归 | 普通有序脚本可本地打开，无固定端口要求；无下钻/财务操作，关键金额完整，原54,000/56,000/59,000保持 |

本次仅核验文档算例算术、字段覆盖和现有计算基线。C01至C16是下一批实现后的验收要求，未声称全部已执行；没有做本批浏览器验收或正式财务平行核对。
