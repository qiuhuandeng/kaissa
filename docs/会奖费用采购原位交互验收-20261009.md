## 1 当前操作路径

| 角色与任务 | 现在从哪里操作 | 保存或返回结果 |
|---|---|---|
| 计调在当前活动录入费用 | 履约中心 → 项目团 → 详情 → 费用采购 → 新增费用 | 一次点击打开表单；项目固定，默认本场活动及日期；保存后当前表格显示并高亮 |
| 负责人或计调处理跨场、整体采购 | 同一新增费用抽屉选择“指定多场活动”或“项目整体” | 不离开项目团详情；保存后自动切到本页“项目采购”查看范围，定位原费用 |
| 在活动中核对项目采购及本场分配 | 同页“查看范围：本场费用／项目采购” | 本场费用显示承担金额，项目采购显示原采购总额及覆盖范围；不增加第二层Tab |
| 维护原采购、分配、申请付款 | 当前表格 → 费用详情 → 对应按钮 | 同一位置切换抽屉内容，有“返回费用详情”；未保存返回有放弃确认，保存后回原详情 |
| 查看付款申请或撤回未付部分 | 原费用详情 → 付款申请记录 → 详情／撤回 | 仍在当前页，始终关联同一原采购；回原费用详情查看更新记录 |
| 跨项目采购或排期前先采购 | 项目团列表 → 项目采购 | 集中台账默认全部可见记录，支持费用／供应商／编号、项目、范围、状态筛选；新增时选择所属项目，不默认首条项目 |
| 项目整体费用核对 | 单团项目详情 → 费用总览 | 只读；可反查原采购，不在项目侧录入或请款 |
| 业务结算与实际付款结果 | 项目团详情 → 结算核对；原财务复核、付款页面 | 结算可选择本场或同项目多场；采购台账不重复铺业务结算和付款空表 |

费用详情操作保留岗位、公司、活动分工和结项控制。销售只读，有采购权限的负责人／计调／销操兼岗才能修改。列表固定“详情／编辑”，已结项不再显示编辑与请款；费用调整保留原后补路径。

## 2 表单联动与金额边界

- **本场活动**：详情继承当前项目、活动及服务日期；集中台账新增则先选项目和单场活动。服务范围在编辑已有费用时不可更改。
- **指定多场活动**：至少勾选同项目两场；各场分配金额可留空，明确显示未分配金额。也可在新增时填写分配金额和依据。数量×单价会同步刷新总额和分配余额。
- **项目整体**：无需选择活动，适用于整体策划、统筹等费用；没有活动也能先采购。需要管理分摊时从原费用详情办理。
- **同一笔采购**：3万元采购分给两场2万元、1万元，总成本仍是3万元。本场行显示承担与采购总额；请款只引用原采购编号及其余额，不能针对分配再建立一份费用或付款。
- **校验与历史**：分配不能为负或超总额，原费用不能改小到低于已分配；已分配或有付款记录不直接更换币种；已取消活动的历史分配保留。无金额显示待确认，未分配显示待分配，不以零替代未知承担。
- **预计调整**：费用采购查看范围为本场费用时调整本场预计，为项目采购时调整项目预计；原批准预算保留，预计上涨不改变客户订单成交价。
- **业务与财务**：采购仍按含税金额录入；付款申请只占有效未付额度，不增加实际付款。实际款票结果、税额核定仍由原财务入口处理，未确认政策不在本轮擅自确定。
