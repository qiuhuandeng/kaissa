## 二、财务真正需要的五类结果

财务需要的不是一张固定格式的周报，而是五类可以使用同一口径互相核对的结果。根据用户2026-09-07的最新专项要求，财务数据看板采用四个顶层Tab，不提供任何点击下钻或弹窗下钻；五类结果作为数据内容被归入四个Tab，明细直接在对应Tab完整展示。

### 1. 财务业绩明细底表

每笔有效订单需要同时具备：

- 订单号、团号、订单日期、出团日期、实际回团日期。
- 产品归属、产品类型、业务类型、目的地。
- 产品负责人、销售人员、销售部门。
- 渠道、门店或分公司、预算区域。
- 人数或商品数量。
- 订单流水、实收、供应商结算价、业务收入和财务确认收入。
- 数据来源，包括通通游、老ERP、新ERP或新系统。

这是订单、回团、渠道、产品、预算和毛利分析的共同基础，不应由各张报表分别加工一套底表。

### 2. 订单口径业绩

订单口径按照下单日期统计有效订单，用于观察“本期新形成了多少销售业绩”。主要指标包括：

- 当周、上周和周环比。
- 当月、上月和月度同比。
- 当年累计、上年同期和年度同比。
- 月度预算、年度预算和预算完成率。

订单取消、部分退款、全额退款、订单变更和跨期冲减规则仍需财务确认。

### 3. 回团口径业绩

回团口径按照实际回团日期或财务确认的回团月份统计，用于观察“本期已经完成履约的业务”。必须能区分：

- 当年下单、当年回团。
- 上年下单、本年回团的跨年订单。
- 已回团但成本或结算尚未完成。
- 回团后发生的成本调整、退款或变更。
- 自营、外采、邮轮、自由行和单项服务在履约完成判断上的差异。

### 4. 产品和渠道分析

财务要求至少能够按以下方向组合分析：

- 产品：参团游、自由行、邮轮、单团、签证、机票、酒店及其他单项服务。
- 旅游范围：出境、国内、港澳台、入境。
- 业务类型：凯撒自营、凯撒甄选、外采。
- 目的地：国家或省份、目的地分区。
- 渠道：呼叫中心、体验中心、门店、全员营销、分公司及其他渠道。
- 区域：京津冀直营、京津冀加盟、非京津冀和预算区域。
- 人员：产品负责人、销售人员、销售组、团控人员。

这些分类必须各自有明确含义，不能把法人公司、产品经营公司、部门、品牌、供应商和业务类型混在一个“产品归属”字段中。

### 5. 毛利、预算和异常管理

产品和经营分析还要求：

- 团队收入、总成本、毛利和毛利率。
- 不含税收入、不含税成本和不含税毛利。
- 单团利润。
- 未提交准单或结算资料缺失。
- 负毛利团队。
- 供应商返点。
- 预付款、已付款、待付款和实际成本。
- 个人、销售组、门店、渠道的月度和年度任务。

异常不能只显示在报表中，还要能回到对应订单、团期、成本或结算页面处理，并保留处理结果。

## 三、共同分析维度

五类结果共用的主要维度包括：

| 类别 | 主要内容 |
|---|---|
| 时间 | 下单日期、出团日期、实际回团日期、结算确认日期、财务确认期间、周、月、季度、年度 |
| 订单 | 订单号、原系统订单号、订单状态、团号、人数或数量、客户类型 |
| 产品 | 旅游范围、产品大类、产品类型、业务类型、产品经营公司、产品负责人、供应商 |
| 目的地 | 国家、省份、城市、目的地分区 |
| 销售 | 销售人员、销售组、销售部门、销售公司、门店或分公司 |
| 渠道 | 渠道、分销商、区域、预算区域 |
| 履约 | 团期、出团、实际回团、团控人员、团队状态、结算状态 |
| 数据来源 | 来源系统、原系统编号、导入批次、重复处理和人工调整原因 |

## 四、共同金额口径

现有材料中的“收入”存在混用，后续系统至少应区分：

- **订单流水**：客户下单时形成的订单应收金额，用于订单口径业绩观察。
- **实收**：实际收到并认领到订单的金额。
- **退款**：已退或应退给客户的金额。
- **供应商结算价**：依据采购或供应商结算形成的金额，不能直接等同于收入。
- **业务考核收入**：经营管理用于业绩考核的金额，计算规则需单独确认。
- **财务确认收入**：财务根据履约和会计期间确认的收入。
- **成本**：已经确认或暂估的履约成本。
- **毛利**：收入减成本；使用哪一种收入以及含税或不含税必须在报表名称和口径中说明。

金额在系统中按元和原币保存；报表可以按万元展示。跨境业务还需保留币种、汇率和折算金额。

## 五、从现有材料发现的重点风险

以下是材料反映出的风险，不等同于对当前新系统代码的结论；必须在阅读项目文档和代码后逐项核对：

1. 同一“收入”列在不同来源数据中可能取订单流水或供应商结算价，口径不统一。
2. 产品归属可能混合公司、部门、品牌、负责人和供应商，无法稳定分析。
3. 产品分类、业务类型、旅游范围和自营外采之间存在交叉，需要分别定义。
4. 渠道和预算区域带有年份版本，历史数据可能依赖人工重分类。
5. 产品负责人、销售组织等历史归属可能随当前主数据变化，需要保留业务发生时的归属。
6. 通通游、老ERP和新ERP数据目前存在人工拼接和排重痕迹。
7. 大量隐藏工作表、外部链接、手工公式和公式错误说明现有周报过程不够稳定。
8. 团号、产品负责人、渠道等字段存在空值；“业务不适用”和“数据缺失”尚未明确区分。
9. 团队结算进度、产品毛利和负毛利等目标表存在空表或不完整结果，说明成本结算链路仍需重点核对。
10. 订单一行可能无法准确承接一个订单中的多个产品、供应商、经营公司、优惠和退款分摊，需核对系统统计层级。

## 六、必须由财务确认的首批口径

- 哪些订单状态进入订单业绩，取消、部分退款和全额退款分别如何处理。
- 订单口径业绩采用订单原金额、退款后净额还是分期冲减。
- 各业务类型何时视为完成履约，实际回团日期如何产生和调整。
- 业务考核收入和财务确认收入分别如何计算。
- 自营、甄选、外采的判断依据和生效时间。
- 产品负责人、销售人员、渠道和区域按照下单时、回团时还是当前归属统计。
- 跨年订单和回团后调账计入哪个期间。
- 供应商返点、预付款分摊、暂估成本和税额如何进入单团毛利。
- 预算调整后，历史报表使用原预算还是最新预算。
