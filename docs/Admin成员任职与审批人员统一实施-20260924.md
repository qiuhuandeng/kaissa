## 角色及操作路径

账号管理员在“部门组织—员工账号”开通、编辑、停用账号，设置可任职公司及角色资料。集团组织管理员进入“组织架构”，选中公司或部门，在“成员任职”中新增或调整主／兼任、直属上级、任期和生效日期。审批管理员继续在审批中心配置模板及公司职责，通过试跑核对实际审批人。业务端仍提交调整申请，不以提交申请直接改动当前关系。

本步是业务原型：没有真实账号服务、短信、后台权限执行或生产组织同步。资料只用于当前原型会话。账号和任职维护可操作、保存可复开，审批试跑读取相同的有效人员及关系。
