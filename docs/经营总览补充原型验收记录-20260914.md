# 经营总览补充原型验收记录

日期：2026-09-14。范围：总体计划阶段3、第5小批前半批，只补经营总览。结论：本批原型通过；不代表正式财务报表上线。

## 一、依据与业务位置

本次依次完整阅读总纲、需求基线、进度和对照表；按进度唯一下一步，对照数据目录、导航、共享报表、经营总览字段方案及订单和回团共同明细。没有重新整理附件或将旧表格中的任务当作现行批准任务。

主要角色为集团、公司负责人及财务分析人员，日常任务是按销售或产品责任核对经营规模、月年累计及任务完成情况。上游为订单确认与变化、实际完成记录和任务资料；下游为经营判断与来源核对。本页只读，不修改归属、结算、收入、成本或预算状态。完整本期来源直接列在页内，不新增业务下钻。

## 二、缺口及本批处理

| 修改前缺口 | 本批结果 | 边界 |
|---|---|---|
| 共同归属未用于总览，销售产品责任分组不足 | 增加分析责任；销售公司、事业部、部门、主渠道、预算区域及产品公司、事业部、经营组共8类分组；共同归属与分类筛选和明细一致 | 不重建组织，不从当前任职覆盖发生时资料 |
| 本期没有金额的组织会从月年累计中消失 | 按本期、月累计、年累计出现的组织保留分组 | 同期独有组织需待完整同期接入，本批没有伪造 |
| 同比替换年份可能产生无效闰日；快捷期间不遵循选择的结束日 | 上期采用相邻等长天数，上年同日取有效日期；月、季、年、7日、14日按所选结束日计算；错误范围不覆盖已有结果 | 闰日取上年2月末为演示约定，正式统计日历与考核规则待确认 |
| 三种完成率的分子、分母期间不清，集团算例无法识别新增筛选 | 月度、年度、累计进度分别列出实际期间、任务期间、金额、版本及计算依据；任一归属筛选均不借用集团月算例 | 不读取P7草稿；无批准任务、年度任务或同进度分解则不计算；变化额不套任务 |
| 趋势与来源未完整采用共同归属 | 本期、月年累计、趋势及来源采用同一明细筛选；导出包含任务、比较日期、趋势及完整本期来源 | 空趋势期间为未提供样例，不补零；没有完整同期不显示实际增长率 |
| 部分金额缺数容易只展示已知合计 | 区分已知金额与缺失条数；缺金额不计算完成率 | 不补造收入、成本或业务毛利 |
| 已售未完成的时点容易误解 | 明确显示数据截止日全部未完成安排，含到期未确认和未来跨年 | 不是查询结束日历史余额，不做历史还原 |
