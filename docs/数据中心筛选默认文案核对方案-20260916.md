# 数据中心筛选默认文案核对方案

2026-09-16，用户已确认并完成实施。下文盘点为修改前证据。

## 核对结果

检查17菜单93Tab，展开更多筛选，发现10个菜单32Tab有默认项或选中项仅显示“全部”，共250个重复展示位置（按Tab计数，不是独立字段数）。无页面脚本错误。部分“全部年份、全部状态、全部范围”等也无法明确识别字段。

原因：共享样式隐藏了字段名称及分组标题，部分通用下拉框仍输出“全部”。问题也涉及常用筛选，不仅是更多筛选。巡检覆盖默认Tab状态，不代表穷尽所有联动组合。

## 统一方案

- 不限范围选项写“全部＋业务字段名称”，保留原筛选值和查询范围。
- 日期、版本、统计层级、金额单位等具体默认值保持原意。
- 待补充、待确认、未归属、不适用仍作为独立选项。
- 保持现有布局、12px间距、自然换行和更多筛选位置；长名称在实施时核验是否完整显示。
- 具体值选中后仍可能难辨字段，建议补充字段名称提示；是否恢复常驻标签属于另一项交互选择，本次不默认增加。
- 只改文案，不改计算、排序、导出金额，不恢复已撤回的排序改造。
