# 确认明细与结算对照主表重组验收

2026-09-15｜整体方案6.14｜原型交付

## 一、角色与业务位置

核算会计按会计期间核对收入确认、成本结转和调整；业务结算人员按实际完成范围核对业务结算与累计财务确认。上游复用回团确认及分配来源，下游损益和凭证核对引用有效会计事项。本页只读，无推送、付款或修改确认动作。

## 二、财务要求—现有功能—缺口—修改页面/流程—验收

|财务要求|原现状与缺口|本次修改|验收|
|---|---|---|---|
|确认明细一笔确认一行|旧主表按完成分配拆行，依据表又平铺|收入/成本确认记录主表，同主题切换完整分配及未分配组成|37确认记录不重复；有效记录金额等于分配加未分配|
|异常确认可发现|冲突记录只在依据表，主发生额无记录|保留异常确认主表行，金额未知，原因明确|同源冲突不会当有效金额|
|会计期间与完成日期分开|结算对照显示无实际作用的会计期间筛选|确认明细按会计期间；结算对照按实际完成日期，截至资料日累计确认|隐藏期间变化不截断累计成本；跨月测试|
|结算和确认不可互代|结算收入、已确认收入和成本含义不同|分别保留，部分确认或未提供直接标明|业务结算10000但财务确认未提供，不推收入|
|不错误计算结算差额|原来源difference是收入减成本|不将该字段当业务结算与确认差额展示|主表无错误差额列；原来源算法未改|
|组成不混范围|完整来源和分配平铺，存在全票式重复风险|确认按关联订单选整笔确认，组成保持整笔；结算按完成记录选本项业务结算/收入/成本份额|订单筛选不引入无关未分配确认；状态筛选同步组成|
|暂估和跨期调整可核对|多个依据区影响阅读|原确认、原期间、暂估、原因放可选字段，签名金额保留|暂估冲回及实际成本累计6200|
|两个主题一表并可验收|原3/4表同时显示|独立主表与同主题组成切换，查询结果/草稿独立，错误禁导出|本地/HTTP、导出、刷新、1440/768、左对齐及只读|
