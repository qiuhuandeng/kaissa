# 回团财务确认原型验收记录

日期：2026-09-14。阶段4第7小批后半批，仅完成只读业务原型，不代表正式财务取数或会计政策批准。

## 一、入口和交付

入口：数据中心 → 经营报表 → 回团明细 → 财务确认资料。可直接打开本地 `merchant/data/return-report-details.html`，无需8002端口，项目共享资料目录须完整。

面向结算会计、核算会计及财务分析人员，核对履约完成后的收入、成本、确认发生和分配依据。上游的履约、业务结算、财务确认各自独立；下游仅供分析和核对，不产生付款、结转或凭证。

- 完成业务核对：按实际完成范围查看截至资料截止日的累计确认；保留已完成但缺会计资料的业务。
- 确认发生明细：独立按会计期间或财务确认日期查收入、成本与调整，不受实际完成月份限制。
- 两种方式各12个默认字段，分别保留查询条件、排序、分页、可选字段；修改条件未查询时，表格、合计及导出继续对应原查询。
- 原确认与调整依据、金额分配依据直接列于主表下方，支持完整导出，不增加业务处理按钮或新菜单。
- 核算主体、账簿、原币及金额口径分别合计，未分配单列；缺确认不填0，业务结算不转作会计收入。
- 默认共同资料与独立财务算例分别选择。共同6条完成记录的成交参考仍为56,000元，确认收入及结转成本未提供。

原实际完成、未来安排、完成后调整三个主视图保留；未修改团期订单、源业务页面或并行门店专项代码。

## 二、逐项验收

下表为独立算例的计算验证，不是正式财务样账核平。RF编号对应原任务卡。

| 场景 | 本批验证结果 |
|---|---|
| RF01 完成待确认 | 业务结算10,000、业务成本7,000不补成会计金额；完成行保留，差额无法计算 |
| RF02 跨月确认 | 5月发生收入10,000、成本11,000；5月完成业务截至6月累计6,000/4,000，两种范围不强求相等 |
| RF03 跨期后补 | 原10,000/7,000和后期-500/+200分开，累计9,500/7,200，差额2,300 |
| RF04 分次完成 | 一单两次完成，收入4,000+6,000，来源成本只计6,000，不重复为12,000 |
| RF05 部分分配 | 来源12,000=已分配9,000+未分配3,000；按A公司查5,000，余款不猜成A业绩 |
| RF06 分配异常 | 原600分配700阻止计入；截止后才确认的200在原截止保留未分配 |
| RF07 净额与代付 | 净额收入2,000减适用结转成本300为1,700，代付款8,000不再次扣除 |
| RF08 价税与外币 | 不含税10,000减7,000为3,000；USD100独立，不猜汇率；原确认价税合计及税额标为仅核对 |
| RF09 重复及状态 | 同源1,000重传只计一次；待批和驳回不生效；1,000/1,200冲突列异常，不任选金额 |
| RF10 暂估与冲回 | 5月6,000、6月净增加200、累计6,200；缺有效冲回不把暂估和实际成本重复计入 |
| RF11 退款及发票 | 退款执行和发票纠错只作依据，不再次冲减已确认收入 |
| RF12 日期和截止 | 业务确认日、会计期间、生效及资料记录时间独立；迟到资料不进入较早截止结果 |
| RF13 阶段及更正 | 未来完成不进入当期完成范围；有效阶段确认可进入发生明细，不自动更改原会计期间 |
| RF14 未匹配 | 有效成本800保留未分配，业务筛选不猜门店归属 |
| RF15 多主体 | 销售A、产品B、签约C不替代核算D；B/D确认分别计，未做集团内部抵销 |
| RF16 缺数与零 | 明确确认且范围完整的成本0可显示；没有结转记录仍为未提供 |
| RF17 查询及导出 | 实际点击验证两方式条件独立、待查询隔离、分页、排序、选列、无效查询保留结果、空态和全量依据导出 |
| RF18 原型兼容 | 本地HTML、随机端口、旧页菜单延迟依赖均可进入；1440及390像素截图核对，表格内部滚动，关键金额未裁切 |

另有4项边界测试：分配更正版本只替代有明确依据的原版本；错主体/币种和原确认关联阻止计入；缺确认时间/依据/确认人仍列异常而非静默丢弃；产品负责人筛选不混用会计确认人，完成核对选择净额收入仍保留适用成本。
