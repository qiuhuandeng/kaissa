## 角色与链路

财务往来会计从数据中心 → 资金核算 → 预款余额 → 款项变动进入，选择预收、预存、预付或保证金，按账户核对期初、期间记录和期末。上游复用期初确认及已确认增减、冻结解冻、分摊和应退记录；核销及退回办理仍在财务业务菜单，报表只读。

## 边界与遗留

- 记录金额不等于银行现金；使用、冲抵、批准损失、分摊、应退和冻结均按各自性质列示。期初、期末行不是期间发生，不相加为收入或支出。
- 期初为开始日前已有余额，期末为结束日余额，两者与事件使用同一资料截止。无精确时刻的同日记录沿用来源顺序，不声称还原银行日内顺序。
- 本页不修正原始坏数据，不回写业务；未分配预付余额、完整订单对应、正式资料及权限仍待交接。
- 当前16入口82Tab，其他12多表Tab及整体方案其他新增能力仍未完成。原8批及并行计划、门店线保留。
