# 产品经营补充原型验收记录

日期：2026-09-14。范围：总体计划阶段3、第5小批后半批，仅补产品经营。原型验收不代替正式财务取数、口径批准和上线签认。

## 一、依据与角色

依次完整阅读总纲、财务需求基线、进度与修改对照表；盘点数据中心目录、导航、共享报表、现有测试，对照产品页字段方案及初版验收，与订单和回团共同明细成对核对。原产品初版关于负责人全部缺失、按产品组推公司及P3下一步的内容已补时效说明，保留历史记录，不删除旧文档。

本页由产品负责人、事业部负责人及财务分析人员使用，用于查看产品责任业绩、产品与供应结构、渠道贡献及跨年已售。上游引用订单确认、实际完成和发生时组织资料，下游用于经营判断及来源核对。不修改产品归属、订单、履约状态、收入、成本、结算或任务状态。

## 三、业务算例

以下均为演示金额，单位人民币元，不是财务实绩。

| 场景 | 结果 |
|---|---|
| 5月1日至7日订单 | 产品A25,000、B29,000，共54,000；实际回团合计56,000 |
| 跨主体 | A销售/B产品10,000，不重复增加集团规模 |
| 负责人 | 已明确30,000，待补充24,000；负责人乙10,000；产品领导甲25,000 |
| 仅查5月7日 | A产品本期0、月累计25,000、年累计30,000仍显示；不因本期零而删除组织 |
| 产品供应结构 | 自营19,000+内部供应10,000+外部采购25,000=54,000 |
| 缺分类 | 目的地未知19,000仍计总额；经营分类缺确认不按供应关系猜，地理和管理分区可分别筛选 |
| 渠道贡献 | 呼叫中心跟团29,000，占该渠道100%；同类型全渠道39,000，贡献74.36%。限定A呼叫中心部门后分母20,000，不恢复集团全部 |
| 跨年 | 全集74,000=已完成56,000+未完成18,000；次年未完成9,000。实际完成年份2027为空，不把计划到期当回团 |
| 缺金额 | 已知100与一条未分配并列，合计显示已知额及缺数；全未知不是0，渠道及结构比例不计算 |
| 日期 | 2024-02-29上年同日取2023-02-28；4月20日选月累计为4月1至20日；超过数据截止日拒绝查询并保留原结果 |

闰日处理仅为演示约定。任务区完整月分母截至月末、完整年分母截至年末、累计进度分母截至查询结束日；没有批准任务及同进度分解时均未计算，不读取P7草稿或集团月算例。

## 五、遗留和唯一下一步

正式完整同期、自然周/管理月/闰日规则、可比组织、产品与部门领导完整任职、批准任务、同进度分解、财务取数与权限仍未接入。本次仍为演示资料，不能据此停止人工周报。负责人以来源人员资料列示，不据姓名建立跨组织人员业绩排行；正式人员编号仍需来源补齐。

跨年收客固定为数据截止日2026-05-07的有效已售，不支持任意历史时点还原。未提供收入成本时不推毛利；未确认财务自营/甄选/外采分类不推税务或收入确认方式。本期来源只对应本次查询，月年累计来源可另选对应期间核对；报表间新增条件不做自动跨页传递。

唯一下一步：阶段4第6小批前半批P4“团期毛利与结算分析”。先对照字段方案与成本/结算来源页面，明确正常、未结算、成本缺失、负毛利及二次调整的基础版字段和验收，再实施该分析页。采购返点P10另批，不将渠道毛利还原或源结算自动化顺带纳入，团期订单继续不动。
