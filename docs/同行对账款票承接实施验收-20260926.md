# 同行对账款票承接实施验收

日期：2026-09-26。状态：本轮页面原型已完成并验收。接续采购确认与实际服务依据，不新增菜单。

## 一、使用岗位、入口和下一步

| 谁办理 | 现有页面和本轮入口 | 核对与处理 | 下一步交给谁 |
|---|---|---|---|
| 计调／对账经办 | 履约中心→团期结算→供应商对账→已确认单详情 | 查看双方确认版本、实际费用和款项；详情关联供应商账单、应付、冲抵、付款复核、付款记录、票据核验。原业务付款申请入口保留 | 财务应付岗核对；需要申请时仍从原业务付款申请办理 |
| 财务应付岗 | 财务→成本应付→供应商账单／应付管理，本单详情 | 将双方确认版本和原账单、应付对应，保存财务核对依据；已有应付沿用原号 | 预付可冲抵的转预付管理；付款申请交复核岗 |
| 财务应付岗 | 财务→成本应付→预付管理，本预付单冲抵 | 选原预付，核对公司、供应商、币种、可用余额和应付占用，再确认本次冲抵 | 应付余额成为后续付款依据；本步不产生新的银行付款 |
| 付款复核岗 | 财务→成本应付→付款申请，本单复核 | 核对原申请、付款公司、双方确认版本及可申请金额；送审或退回原申请人 | 审批人；复核提交不能变成已经付款 |
| 资金岗／出纳 | 财务→成本应付→付款执行，本付款单 | 对已有获批付款单核账户，提交本页付款演示，登记成功或失败；失败可重试 | 成功结果交原回单核销；异常保留本付款单处理 |
| 发票岗 | 财务→资金票据→发票管理，本票核验 | 按材料核购销方、币种、金额，记录核验依据或退回补正原因 | 通过保留核验结果；退回交供应商票据人员 |
| 供应商对账人员 | supplier→对账结算→已确认单详情 | 查看已冲抵、实际已付、剩余未付、付款占用及尚可申请金额；沿用材料提交 | 业务差异给计调，票据核验给财务；没有内部财务操作入口 |

财务导航实际将票据列于“资金票据”，沿用该现有菜单。各页保留原其他业务及详情；本次不是另做一套付款系统。

## 二、数据和金额关系

本轮主例为福建凯撒向北京国旅地接部采购，CNY，对账单 `DZ20260926003` 第1版，对应 `KS20260908003`、`JP20260908003` 与协议 `AGR-GL-FJ-013`。对账应结101,000，沿用本例应付 `AP-DZ-003`，不因关联供应商账单再新增一次成本或应付。

| 核对项目 | 基线金额／说明 |
|---|---|
| 双方应结 | 101,000 |
| 已冲抵预付款 | 30,000，原冲抵记录HX03 |
| 实际已付尾款 | 50,000，原付款记录FK03；不包含已冲抵预付 |
| 剩余未付 | 101,000－30,000－50,000＝21,000 |
| 已有付款占用 | 10,000；获批付款单待付，尚未计实际已付 |
| 尚可申请或冲抵 | 21,000－10,000＝11,000 |
| 原预付余额 | 预付35,000，已冲抵30,000，剩5,000 |
| 原待复核申请 | 新申请11,000；复核时不再次减30,000预付 |
| 发票材料 | 101,000，按应结金额核验，不能错用21,000未付余额作为票面上限 |

六页是同一基线的独立办理示例：本页修改不自动改变其他页面。冲抵5,000后，本页未付16,000、可申请6,000；申请11,000送审后，本页占用21,000、可申请0、已付仍50,000；获批10,000付款失败不增已付，重试成功后本页已付60,000、未付11,000。

已有获批10,000的申请为 `FK-DZ-003`；本轮待复核11,000为 `FK-DZ-003-NEW`，不是同一申请金额前后矛盾。各页只演示本岗位能做的动作，不在财务复核页批准自己的申请。

## 三、正常与异常处理

- 对账未双方确认时显示缺口和计调承接方向，不开放本次尾款办理。此条件只用于本次最终对账费用；原行前预付／保证金业务保留，未加“必须先最终对账”的全局限制。
- 每个财务详情显示对账单和版本。关联入口带本单与版本；旧版本不自动套新记录，陌生单号不打开固定样例冒充本单。应付可反查回原对账详情。
- 同笔冲抵、陈旧办理版本、零／负／超额／多余小数均拦截；占用中的付款金额不能再拿去冲抵。跨公司、供应商、币种不直接混冲。
- 本例无跨公司代付批准资料；选其他公司或未核准账户提示补批准依据，不把“集团内公司”自动当成允许代付。正式代付政策仍待财务确定。
- 提交付款只进入付款中；成功必须有未重复的银行交易号、已发生日期及依据；失败只解除本单占用，不把失败额算成已付。结果未明时仍保留付款中，不能默认成功。
- 票据核验与付款分别保存。核验通过或退回补正均不改变应付金额和已付款；退回保留原票号、材料、金额和原因，不以删除发票掩盖异常。
- 未保存退出及关联页面跳转有放弃确认。办理状态变更后，本行、状态计数和当前筛选同步更新。
- 本例先款后票、核准账户及付款日期范围是演示资料，不将其推广为集团统一财务政策；没有自动税控验真或真实银行扣款。
