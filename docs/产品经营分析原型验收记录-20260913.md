## 业务范围

本轮按用户“执行”授权，只制作产品经营分析。主要给产品、事业部及财务负责人核对经营贡献和产品结构；上游引用订单发生时产品归属及实际完成分配记录，下游为经营判断及两套明细核数。页面不编辑产品归属、不确认成本、不处理订单或结算。

入口：数据中心／经营报表／产品经营。新页面为merchant/data/product-reports.html，旧product-analysis.html仍在历史方案，不覆盖其运营分析。已检查旧页代码和导航、盘点及审计文档引用。

## 页面验收

| 视图 | 可检查内容 | 演示验收结果 |
|---|---|---|
| 经营组业绩 | 按产品经营公司、事业部、经营组汇总；销售公司与产品公司分别筛选；订单与实际回团分别查 | 订单产品A25,000/B29,000，共54,000；实际回团56,000；销售A产品B组合10,000 |
| 产品结构 | 产品类型、主归属目的地、旅游范围及业务线；自营组织、内部供应、外部采购、供应关系待归类 | 订单19,000＋10,000＋25,000＝54,000；目的地待补充19,000仍纳入合计 |
| 渠道交叉 | 所选渠道金额、渠道内构成、同产品全部渠道额及贡献比例 | 呼叫中心跟团29,000，占所选渠道100%；全渠道跟团39,000，贡献74.36%；全产品分母54,000 |
| 跨年收客·计划年份 | 截至日全部有效已售，分订单确认年和计划完成年；完成及未完成分列 | 74,000＝完成56,000＋未来18,000；目标2027年为未来9,000；部分项目完成4,000／未完成6,000 |
| 跨年收客·实际年份 | 只含已实际完成，分订单确认年及实际完成年 | 56,000；其中2025订单2026完成15,000；2027年无已完成样例 |

金额单位均为人民币元。页面可切换元／万元，全部为非财务实绩的演示数据。

渠道贡献分母只解除主成交渠道条件，仍受原销售公司、产品责任、门店、来源及期间限制。例如筛销售A公司时全渠道分母35,000，再限定A电销一组时分母20,000，不擅自恢复集团全部。

多目的地记录按唯一主归属目的地计数；途经国家列表不扩增成交额。集团内部供应保持独立供应关系，不直接认定为集团正式“外采”或“甄选”分类。
