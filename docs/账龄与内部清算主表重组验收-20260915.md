# 账龄与内部清算主表重组验收

2026-09-15｜整体方案6.10｜仅完成既有两个主题重组，独立逾期与往来变动尚待下一步。

## 角色与上下游

往来会计从数据中心 → 资金核算 → 往来账龄进入。账龄用于判断已确认债权债务存续多久；内部清算用于判断代收代付形成的双方记录是否对应、余额是否一致。上游为确认、有效调整、核销、冲回及双方对应记录；下游处理仍回财务办理菜单，报表只读。账簿指公司具体核算记录范围，不同账簿不混加。

## 边界与遗留

- 当前资料仅支持代收代付，未伪造内部购销、银行调拨或集团抵销。清算双方账簿分别保留；不相加成集团余额。
- 账龄分段沿用原型约定，正式分段政策待财务确认。到期日期筛选只限定范围，不改变确认日起算依据。账龄已收敛为往来单位分布，渠道、部门等仍可作为筛选，原渠道/部门分布组合不作为本轮主表保留。
- 调整与核销发生不是余额组成颗粒度，不再作为本页平铺表；原模型保留。独立“往来变动、逾期分析”仍待实现，不宣称能力已全部补齐。
- 应收余额、应付余额、订单收付保留；往来账龄当前5个Tab各1表。16入口79Tab，全站多表Tab由18降至16。原8批完成状态及并行计划、门店工作线不变。
- 独立算例不是正式账务，真实来源、权限及实账核对未交付。
