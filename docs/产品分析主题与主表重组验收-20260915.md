# 产品分析主题与主表重组验收

2026-09-15。依据整体方案第6.3节、进度第三/四节指定的产品分析三个多表主题及用户“执行”。

## 使用角色与业务位置

产品经营负责人、事业部负责人及财务业务伙伴，分别判断产品成交、实际完成、跨年安排和确认后的直接经营贡献。订单与完成引用共同业务明细；贡献引用同公司、原币、会计期间的确认及直接费用资料。页面只读，源单据确认和费用分配仍在业务/财务办理模块，不能由报表自动创建或回写。

## 本轮边界与遗留

- 本轮完成三个多表主题的结构改造及其日期主题直接影响，不宣称整体方案第6.3节全部财务能力完成。
- 产品考核金额与订单成交额可能不同；现有资料未提供逐产品已确认考核金额，未用成交额或供应方式代替。正式产品系列/线路层级、旅客人次、批准任务与完整同期仍待补。
- 已分配公共费用、逐产品待分配费用需要实际分配来源，不能把全公司未分配金额重复挂给每个产品。本轮保留直接贡献口径，完整产品利润待后续费用分配能力补齐。
- 跨年页面按计划完成年组织已售安排，实际完成主题在产品回团；原模型仍保留实际年份规则供核验。本页不提供任意历史截止状态还原。
- 产品风险保持既有资源风险范围，本批未扩展预计毛利等未确认来源。
- 订单/完成资料截至2026-05-07，确认贡献为独立9月算例；两套金额不当同期间财务实绩。正式来源、政策、权限和实账未验收。
- 全公司核对依据继续归核算核对与月度损益，未删除这些专题能力，源办理页、团期订单、并行门店及甲方计划未修改。
