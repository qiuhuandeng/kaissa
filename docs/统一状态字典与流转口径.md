# 统一状态字典与流转口径

业务确认辅助稿 v1.0  
编写日期：2026年8月2日  
适用对象：销售、门店、产品计调、外采、供应商运营、邮轮、航服、财务、法务、系统产品负责人

本文用于统一各流程确认稿中的状态口径。正式页面可以按岗位展示简化文案，但底层业务含义应保持一致，避免“销售看到已确认，财务以为已收款，计调以为已可出行”的误解。

## 一、状态使用原则

1. 一个业务对象只保留一个主状态，主状态说明对象处于哪一阶段。
2. 收款、合同、履约、资源、成本、结算、NC 是不同维度，不应混成一个状态。
3. 待办和风险不是主状态，只用于提醒、筛选和阻塞说明。
4. 已推 NC、已关账、已结算的数据不直接改原状态，后续通过调整、冲销、二次结算或反结算处理。
5. 各文档若出现同义状态，应以本文状态字典为统一口径。

## 二、订单主状态

| 状态 | 含义 | 可继续动作 | 不代表什么 |
| --- | --- | --- | --- |
| 意向 | 客户有需求，但尚未形成正式订单 | 跟进、转预订、关闭 | 不占用库存，不生成正式应收 |
| 草稿 | 销售或门店已录入订单信息但未提交 | 编辑、提交、删除 | 不代表客户确认 |
| 预留 | 客户意向明确，系统临时保留资源或名额 | 收款、确认、取消、到期释放 | 不代表资源最终确认 |
| 占位 | 已按规则占用名额、舱房、铺位或资源 | 补资料、收款、确认、释放 | 不代表财务已收款 |
| 待确认 | 需要计调、内部主体、供应商、船方或航服确认 | 来源方确认、补差、改期、取消 | 不代表可最终签约 |
| 已确认 | 业务订单成立，进入合同、收款、资料和履约 | 收款、签合同、补资料、履约 | 不代表已收齐或已出行 |
| 执行中 | 已进入出行或服务执行阶段 | 变更、补差、异常记录 | 不代表已结算 |
| 已完成 | 出行或服务完成 | 结算、售后、发票、报表 | 不代表财务已关账 |
| 已取消 | 订单被取消，需要处理资源、应收、退款或转款 | 退款、转款、释放资源 | 不代表钱已退完 |
| 已作废 | 订单不再作为有效业务对象 | 查看、审计 | 不应用于已收款、已履约订单的简单删除 |

## 三、收款与应收状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 未收款 | 已形成应收，但没有确认收款 | 销售、门店 |
| 待认款 | 系统有流水或收款线索，尚未绑定订单/应收 | 销售、门店、财务收款岗 |
| 待复核 | 销售已认款，但需要财务确认 | 财务收款岗、认款复核岗 |
| 部分收款 | 已确认收款小于应收 | 销售、应收会计 |
| 已收齐 | 已确认收款覆盖当前应收 | 财务收款岗、销售 |
| 待核对收款 | 有付款凭证但未找到真实流水 | 销售、财务收款岗 |
| 退款中 | 退款申请已通过或财务处理中 | 退款会计、出纳 |
| 已退款 | 退款执行完成并回写订单 | 财务 |
| 转款中 | 已发起转款，等待审批或财务核销 | 销售、财务 |
| 已转款 | 原订单收款已转入目标订单或预存 | 财务 |
| 已关闭 | 应收经审批关闭、冲销或转坏账 | 应收会计、财务主管 |

## 四、合同状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 待生成 | 订单尚未生成合同或确认书 | 销售、门店 |
| 待审核 | 合同内容或特殊条款需审核 | 合同经办、法务 |
| 待发送 | 合同已生成，尚未发送客户 | 销售、合同经办 |
| 签署中 | 客户或我方正在签署 | 客户、销售、合同经办 |
| 已生效 | 签署完成且满足生效条件 | 合同经办 |
| 需补充协议 | 订单或产品发生变化，原合同需补充 | 销售、法务 |
| 需重签 | 核心条款变化，原合同需作废重签 | 法务、销售 |
| 已作废 | 原合同已作废，保留历史 | 合同经办、法务 |

## 五、团期/航次/班期状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 筹备中 | 产品或团期资料未完整 | 产品经理、计调 |
| 待审核 | 团期已提交，等待审核 | 产品负责人、业务主管 |
| 可售 | 团期满足上线条件，可进入销售 | 产品计调 |
| 销售中 | 已开放销售且可下单 | 销售、门店、计调 |
| 待二次确认 | 订单或资源需来源方确认 | 计调、外采、供应商、航服、邮轮 |
| 截止报名 | 已到报名截止或手动关闭销售 | 计调 |
| 资料锁定 | 已到材料截止，关键资料受控修改 | 名单/签证/邮轮运营 |
| 待出发 | 销售基本结束，进入出团准备 | 计调、履约 |
| 执行中 | 团期、航次、班期正在执行 | 计调、领队、运营 |
| 已回团/已完成 | 出行或服务完成，等待成本和结算 | 计调、财务 |
| 结算中 | 已进入团期或项目结算 | 计调、财务结算 |
| 已结算 | 结算确认完成 | 财务结算 |
| 已取消 | 团期或航次取消，需处理订单和资源 | 产品计调、销售、财务 |

## 六、名单与材料状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 未提交 | 游客资料尚未提交 | 销售、门店 |
| 待补充 | 已提交但缺证件、护照、签证、登船表等 | 销售、名单专员 |
| 待审核 | 资料已提交，等待业务核验 | 名单/签证/履约专员 |
| 已完整 | 已满足当前履约要求 | 名单/签证/履约专员 |
| 已锁定 | 到达材料截止或已提交供应商/船方/航司 | 名单/签证/邮轮/航服 |
| 异常 | 证件过期、姓名不一致、材料缺失或供应商退回 | 销售、履约专员 |
| 已同步来源方 | 已同步给供应商、船方、航司或内部主体 | 计调、外采、邮轮、航服 |

## 七、资源确认状态

| 状态 | 含义 | 适用对象 |
| --- | --- | --- |
| 未申请 | 尚未向资源方提交需求 | 交通、酒店、地接、邮轮、航服 |
| 待确认 | 已提交需求，等待来源方确认 | 外采、供应商、船方、航服 |
| 暂时保留 | 来源方保留资源到指定时间 | 外采、邮轮、酒店、航服 |
| 已确认 | 来源方确认可接待或可出票 | 全部资源 |
| 部分确认 | 部分人数、舱房、铺位或服务确认 | 邮轮、航服、酒店、专列 |
| 无位/不可接待 | 来源方无法满足需求 | 外采、邮轮、航服、酒店 |
| 需补差 | 来源方要求价格或服务调整 | 外采、邮轮、航服 |
| 已释放 | 资源被释放或取消占用 | 团期、机位、舱房、铺位 |
| 已出票/出舱/出铺 | 机票、邮轮舱房或专列铺位结果已落定 | 航服、邮轮、专列 |
| 损耗待确认 | 退改或取消可能产生票损、舱损、铺损 | 航服、邮轮、专列 |

## 八、成本、应付和付款状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 预估成本 | 业务预计成本，未作为最终应付依据 | 计调、采购 |
| 成本待确认 | 需要业务补充供应商、费用项目、金额或依据 | 计调、成本会计 |
| 成本已确认 | 业务确认成本可进入账单/应付/结算 | 计调、成本会计 |
| 待供应商账单 | 等待供应商提交或我方导入账单 | 供应商、外采、财务 |
| 账单待核对 | 账单已进入系统，待匹配成本 | 应付会计 |
| 账单差异 | 供应商账单与系统成本不一致 | 业务、财务 |
| 应付待确认 | 符合应付条件，等待财务确认 | 应付会计 |
| 已形成应付 | 财务确认债务成立 | 应付会计 |
| 付款申请中 | 业务已发起付款申请或审批中 | 付款申请人、审批人 |
| 待付款 | 付款审批通过，等待出纳执行 | 出纳 |
| 已付款 | 出纳确认付款完成 | 出纳、应付会计 |
| 预付待分摊 | 已预付但尚未分配到团期/航次/账单 | 财务、采购 |
| 预付已冲抵 | 预付已冲抵应付 | 应付会计 |
| 付款退回中 | 银行退回或供应商退款待核销 | 出纳、应付会计 |
| 已退回/已核销 | 付款退回或负应付处理完成 | 应付会计 |

## 九、供应商端状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 供应商草稿 | 供应商产品或供给尚未提交 | 供应商 |
| 待凯撒确认 | 供应商已提交，等待凯撒审核 | 外采产品部 |
| 已采用 | 凯撒采购主体已采用 | 外采产品部 |
| 入库审核中 | 代理入库待审核 | 外采产品部 |
| 待包装 | 代理产品尚未完成凯撒销售包装 | 外采产品部 |
| 销售中 | 已可按确认规则销售 | 外采产品部、销售 |
| 订单待供应商确认 | 订单提交给供应商，等待回复 | 供应商 |
| 供应商已确认 | 供应商确认可接待 | 供应商、外采 |
| 供应商无位 | 供应商无法接待 | 供应商、销售 |
| 供应商需补差 | 供应商要求价格或服务调整 | 供应商、外采、销售 |
| 待提交账单 | 已到结算点，等待供应商账单 | 供应商 |
| 待外采审核 | 供应商账单已提交，等待业务审核 | 外采计调 |
| 待财务审核 | 业务审核通过，等待财务应付/发票审核 | 财务 |

## 十、门店对账和分润状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 待生成 | 账期尚未生成对账单 | 财务 |
| 待门店确认 | 对账单已生成，等待门店确认 | 门店店长、门店财务联系人 |
| 有异议 | 门店提交差异 | 门店、财务 |
| 待财务复核 | 财务处理门店异议 | 财务结算 |
| 财务退回 | 财务要求门店补充资料 | 财务、门店 |
| 已确认 | 对账单双方确认 | 财务、门店 |
| 分润预估 | 系统按规则展示预估利润 | 门店、财务 |
| 待财务确认 | 分润待财务最终复核 | 财务 |

| 付款中 | 分润付款处理中 | 出纳 |
| 已结算 | 分润付款或结算完成 | 财务 |
| 已调整 | 分润发生后续调整 | 财务 |

## 十一、发票、结算和 NC 状态

| 状态 | 含义 | 主要处理人 |
| --- | --- | --- |
| 结算待开始 | 业务完成但尚未进入结算 | 计调、财务 |
| 结算中 | 财务正在核对收入、成本和差异 | 财务结算 |
| 结算退回 | 发现未确认事件或差异，退回业务处理 | 财务、业务 |
| 结算已确认 | 结算结果确认完成 | 财务结算 |
| 二次结算中 | 原结算后新增差异处理中 | 财务、业务 |
| 发票待开/待收 | 客户发票待开或供应商发票待收 | 发票岗 |
| 发票已登记 | 发票信息已录入系统 | 发票岗 |
| 发票已验真 | 发票验真通过 | 发票岗 |
| 发票异常 | 金额、抬头、税率或验真异常 | 发票岗、财务 |
| NC 待推送 | 财务事件已确认，待推送 NC | NC 会计 |
| NC 推送中 | 系统正在推送 | NC 会计 |
| NC 已推送 | 推送成功并返回凭证号 | NC 会计 |
| NC 推送失败 | 推送失败，需修正基础信息或模板 | NC 会计、相关业务 |
| 已关账 | 所属期间已关闭 | 财务主管 |

## 十二、跨文档口径修正

| 原文档中可能出现的叫法 | 统一口径 | 说明 |
| --- | --- | --- |
| 已收款、已收齐 | 已收齐 | 表示当前应收已被确认收款覆盖 |
| 待收款、未收款 | 未收款 | 表示尚未确认收款 |
| 待财务确认、待复核 | 待复核 | 用于认款、现金、异常流水等财务确认 |
| 待资源确认、待供应商确认、待船方确认 | 待确认 | 可在页面上显示来源方，例如待船方确认 |
| 已出行、已回团、已完成 | 按对象区分 | 团期用已回团/已完成，订单用已完成 |
| 付款完成、已付款、已结束 | 已付款 | 表示出纳已确认付款执行完成 |
| 已入账、已推 NC | NC 已推送 | 入账口径以 NC 返回凭证号为准 |

## 十三、状态确认方式

业务确认时，建议按以下方式确认状态：

1. 先确认订单、收款、合同、团期、资源、成本、结算、NC 八类状态是否完整。
2. 再确认每类状态由哪个岗位改变。
3. 最后确认哪些状态只展示，哪些状态会阻止下一步动作。

后续页面开发时，状态文案可以根据岗位简化，但不得改变本文定义的业务含义。
