# 供应商类型与准入字段模型

更新时间：2026-07-28

## 1. 目标

供应商管理不能用一个通用抽屉承接所有供给方。地接社、酒店、车队、同业线路供应商、签证服务商、保险服务商的准入资料、业务字段、价格归属和后续入口都不同。集团内部主体公司与体系外供应商不同，应走内部主体共享和内部结算规则，不应按外部供应商 准入处理。

本模型用于约束供应商准入、合作范围、外采产品、团期报价、订单确认和结算的字段归属。后续页面改造必须先按本模型判断，再决定字段和入口。

页面对业务人员不要直接暴露系统建模词。新增供应商抽屉使用“供应商类型、结算信息、我方负责人、拟合作内容、准入资料、准入原因”，准入模板、提供服务约束和权限分组留在后台配置或审核通过后的供应商设置里。结算信息进入财务审核，不代表供应商已具备付款条件。

## 2. 四层概念

| 层级 | 解决的问题 | 示例 | 字段原则 |
| --- | --- | --- | --- |
| 供应商主体 | 它是谁 | 地接社、酒店、车队、同业旅行社等体系外主体 | 只维护工商/资质/联系人/状态，不放产品价格 |
| 内部主体 | 它是谁 | 福建凯撒、北京凯撒、上海凯撒等集团内部主体 | 不走外部供应商 准入，使用内部主体、共享授权和内部结算规则 |
| 合作供给类型 | 它给我们什么 | 单项资源、地接打包、完整外采产品、集团内部共享产品 | 决定准入模板或内部共享入口 |
| 合作范围/权限配置 | 谁负责、看哪里、按什么规则合作 | 欧洲线路合作、东南亚酒店、邮轮舱房 | 维护区域、负责人、可见范围、默认扣点/规则 |
| 业务对象 | 实际被操作的东西 | 外采原始产品、团期、订单确认、结算申请 | 具体行程、日期、库存、价格、订单、结算分散到对应页面 |

## 3. 供应商主体类型

| 主体类型 | 行业含义 | 典型供给 | 不应强制填写 |
| --- | --- | --- | --- |
| 地接社 / DMC | 目的地接待服务商 | 地接打包、完整外采产品、酒店用车导游组合 | 不强制填机票、保险、签证办理字段 |
| 同业旅行社 | 同业批发或完整线路供应商 | 完整外采产品、系列团、目的地参团 | 不强制填车队车辆、酒店房型等资源明细 |
| 集团内部主体 | 集团内共享产品的主体公司 | 内部共享产品、跨公司分销 | 不按外部供应商准入，不强制外部版权/银行资质流程，不使用 供应商端维护自营产品 |
| 酒店 / 酒店集团 | 住宿资源供应商 | 房型、房量、餐标、酒店套餐 | 不强制填逐日行程、地接社联系人 |
| 车队 / 车辆服务商 | 用车资源供应商 | 车型、座位数、司机、用车区域 | 不强制填产品线路、团期对客价 |
| 航空/票务资源商 | 航司、机票代理、锁位供给方 | 航线、锁位、出票、退改签 | 不强制填地接社、酒店标准 |
| 邮轮公司/邮轮资源商 | 邮轮船司或舱房供给方 | 船只、航线、舱型、包舱/切舱 | 不强制填地接打包字段，岸上游另建合作范围 |
| 专列运营商 | 专列线路与铺位供给方 | 车厢、席别、铺位、班期 | 不强制填酒店/地接明细，除非同时做地接打包 |
| 签证服务商 | 签证办理供应商 | 国家、材料、办理时效、出签回传 | 不强制填产品线路和团期库存 |
| 保险服务商 | 保险产品或保险代销供应商 | 保险产品、条款、保单回传 | 不强制填目的地接待、团期报价 |
| 景区/活动/餐厅等单项服务商 | 目的地单项服务资源 | 门票、活动、餐饮、演出 | 不强制填完整线路和系列开团 |

## 4. 合作供给类型

| 合作供给类型 | 定义 | 主要入口 | 价格归属 |
| --- | --- | --- | --- |
| 完整外采产品 | 对方给出可售线路/邮轮/专列/自由行等完整产品 | 供应商端产品、商户端外采包装 | 团期/出行日期/航次维护公开售价和结算价 |
| 地接打包 | 对方承接目的地酒店、用车、导游、门票等组合服务 | 团期成本、项目成本参考、外采产品资料 | 项目成本参考或团期成本，不放供应商主体 |
| 单项资源 | 单个资源或服务能力，如酒店、车、门票、餐厅 | 资源档案、采购履约、团期资源确认 | 资源协议、采购批次或团期成本 |
| 包舱/包列/锁位资源 | 大交通或动态资源占用 | 资源调度、团期资源、履约管控 | 团期/航次/班期或资源采购批次 |
| 代订/办理服务 | 签证、保险、机票代订等按订单办理 | 服务项目、服务单、订单附加项 | 服务项目、服务单或订单明细 |
| 集团内部共享产品 | 集团内主体把自营产品共享给其他主体销售 | 内部产品共享、外采包装视图 | 内部结算规则和团期销售价，不走外部供应商价，不走 供应商端产品上传 |

## 5. 准入字段模板

### 5.1 主体通用字段

所有供应商主体只保留低频、稳定、可复用的主体信息：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 供应商简称 | 是 | 列表和业务选择使用 |
| 供应商主体名称 | 是 | 工商、合同、发票、付款核对使用 |
| 主体类型 | 是 | 决定后续准入模板 |
| 注册国家/地区 | 是 | 境内/境外资质、付款、税务判断 |
| 注册号/统一社会信用代码/税号 | 是 | 合同、财务、税务核对 |
| 主联系人 | 是 | 准入、合同、供应商端开通联系 |
| 供应商来源 | 是 | 新拓展、历史合作、产品指定、集团内部等 |
| 主体状态 | 是 | 草稿、准入中、启用、停用、黑名单 |

### 5.2 结算信息字段

结算信息是供应商财务主数据，新增供应商时可采集，提交后必须由财务审核：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 拟合作有效期 | 是 | 准入阶段用于审核合作周期，正式合同有效期以合同管理为准 |
| 结算方式 | 是 | 月结、单团结算、预付+尾款、现结 |
| 开户名称 | 是 | 必须与合同/发票主体或授权收款主体一致 |
| 开户银行 | 是 | 财务付款核对使用 |
| 银行账号/IBAN | 是 | 境内账号或境外 IBAN |
| 开户行地址 | 按需 | 境外或部分银行付款需要 |
| 币种 | 是 | 人民币、美元、欧元、日元、港币等 |
| Swift Code | 外币必填 | 境外付款使用 |
| 联行号 | 境内按需 | 境内付款使用 |

### 5.3 合作范围/权限字段

合作范围只解决合作边界，不重复主体信息；新增供应商抽屉只填写我方负责人和拟合作内容，更多权限配置在审核通过后维护：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 合作范围名称 | 是 | 例如欧洲线路合作、东南亚酒店、邮轮舱房 |
| 提供服务 | 是 | 完整外采线路、地接打包、单项资源等 |
| 服务区域/目的地/资源范围 | 是 | 按供应商类型使用不同口径 |
| 适用产品线 | 是 | 参团、邮轮、专列、自由行、单项服务等 |
| 外采/资源负责人 | 是 | 决定数据可见和待办归属 |
| 内部可见范围 | 是 | 谁能看该业务单元下产品、团期、结算 |
| 供应商端账号范围 | 按需 | 外部供应商开通端口时填写 |
| 默认扣点/平台费规则 | 按需 | 只作默认规则，可被产品/线路/团期覆盖 |
| 结算规则引用 | 按需 | 引用合同或财务结算规则，不在业务单元里做付款 |

### 5.4 组合模板

| 主体类型 + 合作供给类型 | 准入必填资料 | 后续主入口 | 不在准入抽屉里填 |
| --- | --- | --- | --- |
| 地接社 + 完整外采产品 | 地接资质、责任险、线路资料、逐日行程、地接社信息、图片版权承诺、供应商上线承诺 | 供应商端产品、供应商端团期、外采包装 | 具体团期库存、具体公开售价/结算价、客户成交价 |
| 同业旅行社 + 完整外采产品 | 旅行社资质、产品授权/报价资料、逐日行程、接待方信息、图片版权承诺 | 供应商端产品、外采包装、团期报价 | 车队车辆明细、酒店房型明细，除非作为附件 |
| 集团内部主体 + 集团内部共享产品 | 内部主体、产品归属公司、共享范围、内部结算规则、可售渠道 | 自营产品、内部共享产品、外采包装视图 | 外部供应商准入资料、外部免责声明、供应商端产品上传 |
| 地接社 + 地接打包 | 地接资质、责任险、接待国家/城市、酒店/车导标准、紧急联系人、报价规则 | 团期成本、项目成本参考、资源确认 | C 端产品主图、完整外采产品团期价 |
| 酒店 + 单项资源 | 酒店资质、地址、星级/标准、房型、餐标、黑房日、取消规则、联系人 | 酒店资源档案、自由行套餐、团期资源确认 | 逐日行程、地接社信息、系列团期 |
| 车队 + 单项资源 | 车辆资质、车型、座位数、服务城市、司机资质、保险、调度联系人 | 用车资源档案、团期资源确认、项目成本参考 | 产品售价、完整线路资料 |
| 航空/票务资源商 + 锁位资源 | 航线/航班、协议、锁位规则、释放日、定金、出票规则、退改签 | 航空锁位、团期交通资源 | 地接社、酒店标准、产品公开售价 |
| 邮轮资源商 + 包舱/切舱 | 船司资质、船只、航线、舱型、切舱/包舱协议、释放规则 | 邮轮资源、航次/舱型库存 | 普通跟团逐日行程，除非包装邮轮产品 |
| 专列运营商 + 包列/铺位 | 运营资质、线路、车厢、席别、铺位、释放规则、定金 | 专列资源、班期铺位库存 | 酒店/地接明细，除非作为落地接待附件 |
| 签证服务商 + 代订/办理服务 | 办理国家、材料清单、办理时效、拒签处理、出签回传、服务费规则 | 签证服务项目、服务单执行 | 团期库存、线路行程、地接社资料 |
| 保险服务商 + 代订/办理服务 | 保险产品、条款、备案/授权文件、保费规则、保单回传 | 保险服务项目、订单附加项 | 目的地服务能力、团期价格 |
| 景区/活动/餐厅 + 单项资源 | 地址、服务内容、容量、预约规则、确认方式、取消规则 | 资源档案、行程节点、团期成本 | 供应商产品包装、系列开团 |

## 6. 价格归属规则

| 层级 | 可维护内容 | 不可维护内容 |
| --- | --- | --- |
| 供应商主体 | 合同结算方式、账户、税务资料 | 具体产品公开售价、具体团期结算价 |
| 合作范围/权限配置 | 默认扣点/平台费规则、结算规则引用 | 某个出发日的销售价、某个订单的应付成本 |
| 供应商原始产品 | 报价口径、报价依据、是否按团期维护价格 | 具体出发日期价格和库存 |
| 供应商团期/出行日期/航次/班期 | 供应商公开售价、供应商结算价、库存、确认方式、有效期 | 凯撒最终对客价审批、客户成交价 |
| 凯撒外采销售团期 | 凯撒对客价、渠道可售、确认策略、合同拦截 | 供应商主体资质、供应商付款 |
| 订单 | 成交价、应收、补差、退差 | 供应商最终应付成本 |
| 履约/财务 | 实际成本、应付、付款、发票、回执、NC | 产品基础资料和 C 端展示行程 |

## 7. 页面改造原则

1. 供应商列表展示主体识别、主合作范围、状态、供应商端状态、合同截止和负责人，不展示具体产品价格。
2. 新增供应商抽屉按“基本信息、结算信息、准入资料、准入申请”组织，业务人员只选择供应商类型，系统自动呈现对应准入资料，结算信息提交财务审核。
3. 合作范围与权限作为审核通过后的供应商设置，解决区域、负责人、权限和默认规则，不重复供应商主体字段。
4. 完整外采产品的线路资料进入供应商产品页；具体公开售价、结算价、库存和确认策略进入供应商团期/出行日期页。
5. 酒店、车队、签证、保险等单项资源不强制进入供应商产品页，优先进入资源档案、服务项目或采购履约入口。
6. 集团内部共享产品不按外部供应商准入处理，不使用 供应商端维护自营产品，应走内部产品共享、主体间授权和内部结算规则。
7. 页面上发现旧字段与模型重复或归属错误时，必须删除、降级到详情/附件或迁移到正确页面，不能在旧结构上继续叠字段。

## 8. P0 落地顺序

1. 先调整供应商准入抽屉：基本信息、结算信息、准入资料、准入申请四段式。
2. 再调整供应商产品页：保留产品资料、行程、地接社、版权和报价口径，不维护具体日期价格。
3. 再调整供应商团期页：维护公开售价、结算价、库存、确认方式、保留时效。
4. 再调整商户外采包装：审核产品资料、设置凯撒对客价规则、校验低于供应商公开售价。
5. 最后调整订单确认和结算：供应商确认资源后才能签约，回团达到结算点后供应商发起结算申请。
