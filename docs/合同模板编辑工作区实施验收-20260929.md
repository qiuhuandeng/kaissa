## 二、实际页面变化

| 页面／区域 | 本次变化 | 业务操作结果 |
|---|---|---|
| 合同模板新增／编辑：模板信息 | 收起低频基本信息；文书来源统一为使用平台模板、制作公司文书、到平台办理；取消独立合同文本下拉 | 管理员先确定办理方式，避免自行组合重复概念；新增时展开基本信息 |
| 12301／法大大平台模板 | 按合同当事人、行程、费用、约定等分组显示所需资料；选中项右侧核对来源与允许修改的内容 | 不出现自由插入正文按钮；公司、金额、游客范围保持受控；客户意愿不能固定成同意 |
| 公司自有文书 | 文件目录、正文、选中项属性三个区域；直接点击正文文字／填写项／表格 | 固定条款按片段编辑；填写项业务命名；不要求操作人员手填内部位置标记 |
| 插入内容 | 合并为一个入口，提供已有资料、预设明细表、自定义补充填写和固定条款 | 插入在选中位置之后；没有选择时追加到文末；插入后直接配置，重复引用共用同一份资料 |
| 明细表 | 整组来源自动带出，必需列保持完整；可改展示列名、列顺序、增加序号 | 不再逐列选择“姓名从哪个字段取”；改动进入文书和最终预览，名单人数及费用仍按本份合同 |
| 文件与附件 | 用一个抽屉维护必要文件、条件附件及通用补充约定 | 文件目录和签署文件同步；企业授权书仍默认仅供审核，不默认共同签署 |
| 签署设置 | 页面顶部唯一入口；业务管理员可维护；平台模板不展示自由签章位置编辑 | 平台采用模板既定位置；公司文件保留位置样例核对；内容变化后须重核签署及预览 |
| 对接检查 | 默认合同管理员看不到参数入口；切换技术实施身份后可维护；目标表格整组来源沿用既定资料 | 文件方式只显示上传办理配置；平台方式保留参数、逐列转换和异常样例，不把草稿保存当真实接通 |
| 预览与审核 | 增加零行样例，保留分签、多人多日和行内缺项；平台预览明确为ERP参考结果 | 未应用属性在全局保存／预览时先验证；改动后重核、待审只读、退回可修改、原启用版保留 |

现有预设业务列全部属于必需列，不能任意删除；可选“序号”只影响文书展示，不增加平台业务参数。正文制作是本系统可操作原型，不承诺任意Word文件无损导入或真实PDF签章定位。
