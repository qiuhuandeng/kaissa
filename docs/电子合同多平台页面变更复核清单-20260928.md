## 一、按操作顺序复核

| 入口 | 具体变化 | 建议复核 |
|---|---|---|
| [admin接口配置](../admin/interface.html?section=signature) → 电子合同 | 同页维护12301、法大大连接；公司企业认证、经办人、用章和授权各自独立；原记录按平台、公司核对 | 切两个平台，检查公司授权与能力待核实项；相同编号不能串公司或平台 |
| [admin合同模板](../admin/contract-templates.html) | 列表增加平台筛选和平台说明，标准与企业自有模板并存 | 境内12301、邮轮／研学法大大可同时存在，不按业务名称强制唯一平台 |
| [admin模板编辑](../admin/contract-template-edit.html?template=T-CUSTOM-CRUISE) | 每版确定文本来源、签署平台、三种生成方式；维护正文、普通资料、明细表、签署顺序、共同签署文件、各方及位置 | 法大大文件方式无需重复填正文参数；12301平台模板继续保留受控资料对应；修改后重新预览审核 |
| [admin合同规则](../admin/contract-rules.html) | 默认规则只选模板；按公司和产品条件判断；新增独立监管要求 | 重叠冲突不能随便选一条；法大大不自动免报或报12301；不适用须有依据 |
| [admin基础参数](../admin/params.html?section=contract) → 销售签约条件 | 付款与审批条件独立于默认选模；公司通用与邮轮专用分别维护 | 邮轮原付款待确认保持，不被通用先签后收覆盖；审批回原审批配置 |
| [admin角色权限](../admin/roles.html) | 补平台配置、公司授权、模板与字段、规则等岗位权限项 | 集团管理员配置，销售只办理；原型权限项不等于正式后台鉴权 |
| 产品编辑 → 合同模板 | 沿用／指定两种选择保持；候选标明平台并检查公司适用性 | 邮轮可指定法大大；指定失效不自动换其他平台；销售不重复选择平台 |
| [销售合同准备](../merchant/sales/contract-prepare.html?orderNo=ORD-PREP-CRUISE-FDD) | 带入平台、生成方式和签署安排；生成带表格的完整文书；保存送审版本 | 核对名单、监护／代理授权、行程、费用和本次约定；实际文书与审批稿一致 |
| [审批中心](../merchant/approval/approvals.html?type=contract) | 显示本次平台、生成方式和签署顺序；可看正文及生成排版 | 通过仅进入待签；退回修改后必须重预览；改正文、名单、金额、附件或签署安排后不能沿用旧审核 |
| [合同管理](../merchant/sales/contracts.html) | 增加平台筛选；按模板发起，支持平台办理登记／查询／人工证明；独立签署、文件及监管结果 | 超时只查原申请；部分签署不能算完成；取得文件失败不重签；监管失败不回退签署；变更与解除保留原平台和原文件 |
| [订单详情 → 合同](../merchant/sales/orders-detail.html?orderNo=ORD-PREP-CRUISE-FDD&type=cruise&tab=contract) | 显示实际采用模板和平台、游客覆盖、签署与监管结果 | 从已办理订单反查同一合同；不拿订单旧默认模板替换本次文书 |
| [售后处理](../merchant/sales/orders-after-sales.html?orderNo=ORD-PREP-CRUISE-FDD) | 显示原平台、原版本、原平台任务及已签约定 | 合同创建变更依据后到售后查看原文件；新产品规则不替代已签约定；退款单独办理 |

## 二、建议先试四个场景

1. [法大大邮轮](../merchant/sales/contract-prepare.html?orderNo=ORD-PREP-CRUISE-FDD)：补监护人及本次约定→预览→送审→审批通过→合同管理发起。可演示超时、部分签署、拒签、我方盖章、文件待取及监管失败。
2. [法大大研学](../merchant/sales/contract-prepare.html?orderNo=ORD-PREP-STUDY-FDD)：核对两名未成年人的监护签署关系。同一实际签署人要合并代表范围，不要重复两行。
3. [12301平台办理并查询](../merchant/sales/contract-prepare.html?orderNo=ORD-PREP-DOMESTIC-MANUAL)：审核后登记原平台任务及实际文书，再查询原任务。
4. [12301人工核对](../merchant/sales/contract-prepare.html?orderNo=ORD-PREP-DOMESTIC-EVIDENCE)：审核后登记原任务，再补实际已签文件及证明、核对各方与我方章。

常规[12301境内](../merchant/sales/contract-prepare.html?orderNo=ORD-PREP-DOMESTIC)和[12301出境](../merchant/sales/contract-prepare.html?orderNo=ORD-PREP-OUTBOUND)继续沿用统一准备流程。

原型配置在当前页保存、刷新恢复；当前订单办理组可在准备、审批、合同、订单与售后之间交接，换另一个演示订单会替换当前会话组。首次打开订单或售后链接时，没有当前办理记录不应显示虚假的签署成功。邮轮／研学四个具名试用订单采用明确标注的已确认演示条件，公司正式邮轮付款政策仍是待确认。
