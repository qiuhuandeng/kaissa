# 会奖新建／批量建团表格式抽屉优化验收

日期：2026-10-09。最新日期区域调整见文末追加节。范围：用户本轮要求优化新建项目团和批量建团的层次、日期重复填写与操作效率。

## 业务位置与判断

计调／项目负责人从履约中心 → 项目团 → 项目团控建立实际执行场次；上游为已建项目及分工，下游是项目团草稿中的报价、客户约定与执行核对。新建不自动生成财务单据。

原先每场展开整组表单，上百场需要长距离滚动，日期规则生成后仍呈现两项日期输入，误导用户重复填写。本次将频繁核对的场次资料组织为一张表；共同资料只填一次，低频资料按需展开。

## 本次页面变化

| 区域 | 当前操作 |
|---|---|
| 所属项目 | 单个抽屉顶部输入关键词搜索；空关键词不展示候选。选中后原位展开。项目名称、客户／公司／期间轻量展示，更换已填写项目继续确认清空 |
| 新增项目团 | 活动名称、服务类型、计调、开始／结束日期、城市、人数直接填写；客户参考号、名单要求、时刻、预算参考、客户预计金额、结算期限和服务范围在“补充资料”展开。开始日期填写后仅在结束日期为空时补成同一天 |
| 批量共同资料 | 三列排布名称前缀、服务类型、城市、计调、人数及费用预算参考；服务范围按需展开。应用共同资料默认仅补空字段，取消勾选才覆盖已有值 |
| 创建方式 | 手动添加、按日期生成、导入表格。日期规则保留周期／手动日历、排除恢复、三个月预览与翻页；按钮统一为“生成活动清单” |
| 活动清单 | 表格列为序号、活动名称、活动日期、城市／地点、人数、主责计调、操作。生成的日期直接显示，点“调整”才展开本行起止日期，不重复要求填写 |
| 行操作 | “补充”原位展开参考号、服务类型、预算、客户预计金额和服务范围；复制清空参考号，删除仅移除本次未保存行；手动添加新行继承共同资料 |
| 层次与效率 | 生成或导入成功后收起共同资料及创建方式，显示摘要并回到抽屉顶部；10场一页，只渲染当前页，分页前保留输入；添加定位末页，复制定位新行 |
| 核对与保存 | 核对全部页面，错误行着色并显示原因，“查看首个错误”切到对应页并聚焦名称。全部通过才可保存N场草稿，修改后须重新核对；修改日期设置但未生成时展开设置并阻止保存旧清单 |
| UI | 沿用蓝色竖线分区、白底、32px控件及固定按钮底栏；无重复外层卡片和编号步骤圆点。单次640px、批量1000px；1024窗口表格无需横滚，760窗口仅表格内部滚动，操作列固定132px |

## 日期区域精简追加验收

依据：用户本次两条反馈，要求起止日期一行、精简日历预览、集中生成按钮，以及日期方式由二级Tab改成下拉。仅调整同一批量创建抽屉，日期范围与草稿核对规则保持。

- 活动日期列328px，两个日期输入框各130px，以“至”连接，同一行勾选按钮完成编辑；只读跨日日期也一行显示。重新分配其他列，活动名称吸收余宽，操作列固定116px，人数输入72px，可显示四位人数。
- 下拉“日期方式”依次在开始日期、结束日期、每场天数之前。周期规则显示活动周期及星期／月日；手动选日期隐藏周期字段，直接选择日历。
- 日期预览标题和数量在左，翻月小按钮、按需恢复／清空、“生成活动清单”在右；不再单独显示月份范围行和底部操作区。月份仍由三个日历标题标识。
- 删除“点击已生成日期可排除或恢复”、已排除数量、日期已应用／未应用的常驻文案；修改规则未生成时的提交错误仍保留。
- 恢复日期只在有排除时出现；手动模式清空只在有选中日期时出现。两种方式切换保留期间、天数及各自选择。

| 本轮验收 | 结果 |
|---|---|
| 日期方式顺序 | DOM为dateKind、ruleStart、ruleEnd、ruleDays，二级日期Tab数量0 |
| 周期排除恢复 | 10—12月周五13个日期→排除10月2日12个→恢复13个；无排除时恢复按钮隐藏 |
| 下拉切换 | 周期的周五勾选在往返切换后保留，手动10月22／23两个日期也保留 |
| 月固定日 | 月日改22，10—12月实时3个日期 |
| 清空与错误保护 | 清空后0日期、生成禁用；修改日期未生成后点击核对仍阻断并展开日期设置 |
| 行内日期 | 修改单场结束日并完成编辑，核对通过；手动第3场开始日填写后，空结束日自动填同日 |
| 生成及保存 | 两场手选跨日生成，明确确认替换旧清单，补加第3场后3场全部通过并保存，独立测试项目活动100→103 |
