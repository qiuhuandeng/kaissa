# 门店成员角色调整与停用确认实施验收

日期：2026-09-19。

## 页面与业务位置

- 菜单：门店中心 → 门店管理 → 门店成员。
- 页面：`merchant/sales/store/members.html`。
- 运营或店长查看本店成员。角色调整继续走申请；用户本轮明确将停用改成确认弹窗，确认后只更新本页成员状态，历史订单和客户记录保持原样。原型不调用真实帐号或权限服务。

## 当前页面修改

1. “调整”仍打开“调整门店角色”抽屉，只读显示成员、所属门店和当前角色；仅填写新角色与调整原因。移除订单与售后、合同与资料、资金与成员的独立权限勾选。同角色或缺原因不能提交；提交后显示变更待审批，当前角色不变。
2. “停用”改为简短确认弹窗，显示成员姓名、所属门店及停用影响，只有“取消”和“确认停用”。移除原停用抽屉、原因、接手人、草稿和停用审核流程。确认后本页状态立即变为“已停用”，操作列只保留“详情”；取消不改状态，再次确认同一成员不重复停用。
3. 两类操作均只改当前页独立原型样例；停用不改历史订单或客户记录，不做跨页真实帐号禁用。原“观音山门店陈红”保留正常状态，可演示停用。
4. 用户截图指出原两个抽屉大块留白。当前仅角色调整继续使用抽屉，已在本页限定网格顶部对齐、按内容排布、角色选择占整行，并整理标题间距与资料分隔线；停用使用共享的小确认弹窗样式。

## 核验与限制

- HTML标签、内联脚本语法、直接引用元素及差异格式检查通过；财务执行清单检查仍为原8批／36项／6场景且无错误。
- 停用确认独立算例通过：弹窗带入成员姓名和门店；取消不改状态；确认后变为“已停用”且再次打开／重复确认不重复处理。角色调整独立业务算例沿用前次通过结果；原停用抽屉相关算例已失效，不作为本次验收证据。
- 本次没有取得修改后的浏览器实际点击、像素和窄屏证据；视觉及交互仍待独立浏览器可用时复核，不把静态检查记为浏览器通过。
