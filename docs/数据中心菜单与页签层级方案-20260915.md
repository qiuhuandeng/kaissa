## 二、旅游财务的使用位置

数据中心位于订单、履约和财务办理之后。上游是订单成交与变化、实际回团或服务完成、成本结算、收付款、发票、会计确认和批准预算；下游用于经营复盘、资金安排判断、账务核对及报表输出。

- 集团及公司财务：先看规模与损益，再按产品、渠道、业务和供应商解释原因。
- 业务财务：按订单查成交，按实际回团、下船、项目验收或服务完成查履约，再核对确认情况。
- 收付及往来会计：查一笔款、一个客户或供应商的余额，再看票款对应及账务差异。
- 预算及报表管理人员：维护任务、核对预算依据、分类与组织对应，管理报表版本和查看范围。

查询、切换、筛选、导出不改变订单或财务单据状态。任务和规则维护只改变各自管理记录，收入确认、付款、开票、结算和推送仍由财务办理。报表异常直接列出缺口及原单依据，不新增点击金额、编号的下钻路径。

### 名称需要明确的业务范围

1. **回团明细**沿用旅游财务熟悉的“回团”叫法；范围继续包括邮轮下船、专列行程完成、研学闭营、项目阶段验收、自由行及单项服务完成，不强制这些业务生成团期。以“完成类型”筛选区分。
2. **业务毛利**覆盖团期、项目和服务；“毛利明细”按业务类型筛选，不另开团期利润、项目利润、服务利润三套菜单。部门毛利保留原产品公司、事业部、经营组层级。
3. **月度损益**保留公司、经营部门和集团调整；部门损益表示部门承担的经营收入成本费用结果，费用不完整时不能标为净利润。
4. **预款余额**只是菜单总称，不把四类款项相加。预收款是提前收取且用于约定业务的款项；预存款是客户或门店留存供后续使用的款项；预付款是提前付给供应商的款项；保证金是担保用途的收取或支付款项。各自余额和流水全部保留。
5. **凭证核对**承接现有集团财务核算系统的来源、借贷及返回核对，不新增凭证制作或推送；现有核算系统在项目内称NC，界面仍可在对应字段注明系统名称。
6. **批准预算**仍是批准损益和费用预算的只读引用；新增、分解、提交等任务维护留经营任务。订阅设置保留现有草稿表达，不因改名就声称实际发送已接通。

## 五、菜单、Tab、筛选及页面窗口的边界

| 层级或控件 | 只负责什么 | 示例 |
|---|---|---|
| 菜单分组 | 整理同类报表位置，不独立加载内容 | 经营分析、资金核算 |
| 菜单叶子项 | 选择一个完整报表工作区 | 产品分析、往来账龄 |
| 页面Tab | 切换当前报表内部的内容，不去别的菜单 | 产品结构、应收余额 |
| 筛选与统计方式 | 同一结果的范围、日期或观察方式 | 公司、产品类型、渠道、订单/回团口径、按单据/按订单分配、日/周/月 |
| 页内依据表 | 支撑当前结果的原记录及分配、更正明细 | 原款、费用分配、原确认记录 |
| 系统顶部已打开页面 | 返回已经打开的报表，支持并排核数 | 用户主动打开往来账龄、票款核对后保留两个页面窗口 |

“菜单与Tab不重复”按功能落实，不能只把同一报表换一个短名字后继续放在页面内。顶部已打开页面栏属于窗口切换，名称与对应菜单一致，只出现用户打开过的页面；不预置全套报表，不再增加页面内跨报表Tab。它支持财务同时核对多张表，不承担业务分类。

公司、事业部、部门、经营组、门店、供应商、自营/内部供应/外采、产品类型、日期、币种、单位和版本原则上用筛选或汇总方式选择。渠道页的门店与呼叫中心保留专属Tab，因为原有门店和中心/组/顾问表的核对内容不同；具体门店、中心、销售组和顾问仍是筛选，不逐个建立菜单。

经营总览“经营规模”中的订单净值、当期变化、实际回团改为“统计内容”选择；三套现有金额、趋势、比较和来源内容保留，不再套一排子Tab。产品页的订单/回团、跨年页的计划/实际年份、收付页的单据/订单分配、资金页的日/周/月同样属于统计方式，不新增层级。

## 六、财务查询的交互约定

1. 点菜单直接进入报表及默认Tab，不先打开卡片目录，也不在进入后选择“报表主题”。同一个菜单再次打开，回到已有页面及其当前位置。
2. 点Tab必须展示该Tab的结果或该Tab明确的待查询状态，不能新Tab已经点亮、旧表还在下面。已有该Tab结果时恢复它自己的查询条件和结果；首次进入时用适用默认条件查询，条件不足则展示该Tab的空状态。
3. 修改筛选后点“查询”才更新结果。若Tab切换时有未查询条件，保留为原Tab自己的草稿，不应用到另一Tab，不弹确认打断只读查询。
4. 同一含义的公司、币种、期间可以沿用；含义不同则分别保留。订单确认日、实际完成日、会计期间、余额截止日、资金计划日不能静默互换，销售公司、产品公司、记账公司和资金公司也不能机械互换。
5. 导出始终对应当前Tab最后一次成功查询的全量结果，并带已生效条件。当前Tab首次查询未成功时不能导出另一个Tab结果；查询失败保留本Tab上次结果并明确提示。
6. 明细和依据在当前Tab直接查看、筛选和导出。数字、编号、图表和表格行不增加点击下钻；打印仅保留已有收款清单用途。
7. 页面内一层Tab以2至6项为宜；不再套第二层。窄屏可横向滚动Tab栏，并让选中项可见，不换行成多排。仅一个内容时不强设Tab。
8. 返回已打开报表时恢复当前Tab、查询条件与结果；刷新定位当前页面和Tab。任务或规则表单有未保存修改时，沿用编辑离开提示，不能按只读筛选草稿处理。

## 七、相近内容的主查询位置

| 相近内容 | 主查询位置 | 其他报表保留什么 |
|---|---|---|
| 收付记录和账户收支 | 收付明细查业务款项及逐单分配；资金分析查实际账户收支 | 转款、核销不伪装成银行到账；账户内部转账不算新增经营收入 |
| 往来余额和预款余额 | 往来账龄查已经形成的应收应付；预款余额查尚待使用/冲抵等款项 | 共用合法冲抵依据，两个余额不随意净额相抵 |
| 业务毛利和月度损益 | 前者查业务结算成本与毛利；后者查财务期间收入成本费用 | 不因同有收入成本列就合并；业务完成月与会计确认月分开 |
| 完成核对和确认明细 | 回团明细按完成范围看对应累计确认；核算核对按财务期间看确认发生 | 前期业务本期确认不能从全量确认明细遗漏 |
| 内部清算和内部对账 | 往来账龄查未清余额；核算核对查双方确认、期间及核算差异 | 余额核对、双方核算及正式抵销不是同一件事 |
| 产品风险和资源风险 | 完整资源采购批次、跨团成本分配及损耗在业务毛利 | 产品分析保留明确产品范围的风险观察；不复制完整采购台账 |
| 预付占用和预付款 | 完整余额变动、冲抵退回在预款余额 | 供应商分析保留采购决策所需的同源占用观察 |
| 经营贡献和毛利校验 | 产品/渠道分别看自身责任贡献；渠道毛利校验保留专项还原要求 | 专项校验不当作通用渠道利润或员工奖金；企业付款客户继续可筛 |
| 批准预算和预算差异 | 任务预算看预算依据；月度损益比较实际与预算 | 不复制任务维护或完整损益页面 |
| 总览和专题报表 | 完整专业查询在各专题报表 | 总览保留摘要及必要核对依据，不复制整套专题筛选与办理入口 |
