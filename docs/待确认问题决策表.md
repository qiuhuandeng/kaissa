# 待确认问题决策表

业务确认辅助稿 v1.0  
编写日期：2026年8月2日  
适用对象：业务负责人、财务负责人、销售负责人、产品计调负责人、外采负责人、邮轮负责人、航服负责人、门店/渠道负责人、法务/合规负责人、系统产品负责人

本文用于把各流程确认稿末尾的“待确认事项”改成可拍板的决策表。业务方确认时需要区分两类内容：

- **流程确认：** 业务确认现有流程描述是否符合实际工作。
- **规则拍板：** 多个部门之间存在不同处理方式，需要选择一个正式口径。

本文只处理“规则拍板”。拍板后，应回写到对应流程确认稿和后续开发任务。

## 一、决策优先级

| 优先级 | 含义 | 处理方式 |
| --- | --- | --- |
| P0 | 不拍板会影响主流程开发或跨部门边界 | 开发前必须拍板 |
| P1 | 不影响主链，但影响岗位效率、权限或异常处理 | 可随对应模块评审确认 |
| P2 | 增强能力或后续优化 | 可记录为二期或配置项 |
