# 门店类型与三抽屉边界实施验收

日期：2026-09-19。

## 实施范围

- 菜单：门店中心 → 门店管理。
- 页面：`merchant/sales/store/index.html`、`merchant/sales/store/detail.html`。
- 本次只处理门店类型、新增门店、销售设置、财务设置和两类门店详情，不新增菜单，不做真实文件服务、跨页数据库或生产审批权限。

## 页面改动

### 门店管理列表

- 门店类型只保留“自营门店、加盟门店”，原合作门店样例归为加盟门店。
- 自营门店的结算摘要改为公司统一收款和内部核算，不再显示预存、加盟管理费或加盟账期。
- 加盟门店保留单单结／月结、预存、管理费和保证金摘要。
- 详情链接带入门店类型和门店名称，详情页按当前类型展示。

### 新增门店抽屉

- 仅维护档案准入：基本信息、管理归属、类型专属资质和计划启用日期。
- 自营门店显示内部组织归属、资质使用方式和独立资质文件；不显示合作协议和保证金。
- 加盟门店显示管理归属、加盟主体、营业执照和合作协议；协议区明确保证金、管理费和结算条款转财务设置登记。
- 删除可售范围、合同模板、订单能力、结算、支付、预存、管理费和银行账号，避免与销售／财务设置重复。

### 销售设置抽屉

- 保留可售范围、签约主体、合同模板、订单能力、合同控制、主体复核和授权有效期。
- 自营门店标明继承公司规则、可设置门店例外；加盟门店标明加盟授权需审批生效。
- 删除预存扣款、退款转预存和欠费金额等财务配置，只保留订单是否需主体复核。

### 财务设置抽屉

- 自营门店只显示公司统一收款、内部核算、公司支付商户、公司账户和NC辅助核算；加盟账期、预存、管理费和保证金区隐藏。
- 加盟门店显示结算方式、账期、预存、管理费、支付商户、收款账户及保证金约定。
- 保证金约定关联合作协议，维护是否约定、金额、应缴日期和退还条件；已收、已退和余额明确由保证金收退记录产生。

### 门店详情

- 自营门店档案显示所属经营主体、内部组织、主体资质／门店设立资料；隐藏合作协议、保证金和合同到期提醒。
- 自营财务只显示公司统一收款、内部核算、公司账户和NC辅助核算。
- 加盟门店档案显示加盟主体、营业执照、加盟合作协议和根据协议到期日计算的到期提醒；保证金约定归入“收款与结算”。
- 加盟财务显示结算、预存、管理费、保证金约定／实收／余额及加盟账户。
- 资料“查看／续签记录”打开详情抽屉，说明资料来源及当前版本。

## 浏览器验收

2026-09-19用户截图复核修正：此前仅检查分区的 `hidden` 属性，未检查计算后的显示样式；抽屉通用 `.order-desc-card { display: grid; }` 覆盖了原生隐藏效果，导致自营和加盟表单同时可见。现已增加门店类型分区的明确隐藏样式，并在浏览器逐一核对计算样式和可见高度：默认自营时加盟两个分区均为 `display:none`；切换加盟时自营资质为 `display:none` 且加盟两个分区可见；切回自营后加盟分区再次隐藏。沿用主体资质时独立资质编号、有效期和文件隐藏，选择独立经营资质后才显示。页面脚本错误0。此前“切换正确”的验收表述以本次实测为准。

- 列表及新增门店类型均只有自营、加盟两项。
- 新增自营时只显示自营资质；切换加盟后隐藏自营资质并显示加盟主体、营业执照和合作协议。
- 新增门店抽屉内不存在销售或财务配置字段。
- 加盟协议编号缺失时不新增门店并提示具体缺项；补齐后新增加盟门店样例，财务摘要为待配置。
- 自营销售设置显示继承公司规则，抽屉内没有支付方式控件。
- 自营财务只显示自营核算区，公司支付商户不可改，加盟结算区隐藏。
- 加盟财务显示结算和保证金区；保证金金额为0时阻止提交并提示补齐约定。
- 财务设置修改后取消，重新打开恢复原值50000，取消不改变当前配置。
- 自营详情不显示合作协议、保证金、预存和管理费；加盟档案显示执照、协议和到期提醒，保证金结果显示在财务区。
- 加盟营业执照“查看”可打开资料详情抽屉。
- 390px视口抽屉宽367px，底部按钮可见，页面无横向溢出。
- 两页浏览器脚本错误0；HTML内联脚本语法检查通过。

## 原型边界

当前保存、审批和文件选择为当前页面独立演示，刷新后恢复样例；没有建设真实文件存储、跨页数据库、正式审批或财务到账服务。保证金约定与实收分开的业务含义已经呈现，但不伪造真实资金记录。

## 2026-09-19 门店详情收敛复核

门店详情定位为单店档案、已生效销售规则与财务配置的核对页，上游分别是“新增门店”“销售设置”“财务设置”，下游由订单、合同和财务办理页承接。按用户本次明确范围，详情只保留“门店档案、销售与合同、收款与结算”三个 Tab，不再把门店成员、经营报表或总变更记录作为详情 Tab。门店成员沿用独立菜单；经营分析沿用数据中心；销售、财务及收款账号变更记录保留在相应配置区，暂停／恢复门店的本页结果保留在档案区。

- `index.html`：删除财务设置抽屉内用户指定的自营门店说明整行。
- `detail.html` 门店档案：删除截图中的“业务关系”表和页级权限解释；保留当前档案、资质及加盟合作协议／到期提醒；保证金约定只在财务区核对。暂停／恢复操作对象按当前门店名称显示，取消不新增状态记录。
- `detail.html` 销售与合同：保留当前规则及本区变更记录；移除重复的已授权产品样例表。
- `detail.html` 收款与结算：保留当前财务配置、收款账号及本区变更记录；移除重复的资金流水表。自营门店的历史样例不再写加盟预存和管理费；自营公司账户不提供新增／停用操作，加盟门店仍有相应入口。
- 移除“成员与权限”Tab、其详情抽屉及相关脚本；同时删除“经营报表”“变更记录”Tab和重复的页面顶端跳转按钮。页面从6个Tab收敛到3个，保留现有三类业务对象的核对信息。

本轮静态核验：两页HTML标签配对、内联脚本语法、三个Tab与面板一一对应、无失效的直接ID引用、`git diff --check`均通过。尝试启动Playwright失败（工作区未安装该包）；随后尝试本机Chrome UI，Computer Use 返回“permissions are not granted”，因此本轮未完成浏览器点击或视觉验收。此前浏览器结果仅对应当时版本，不作为本轮三Tab验收结果。

## 2026-09-19 三Tab宽度与间距修正

用户截图显示“收款与结算”的上方信息区铺满内容区，但下方三个表格被产品详情通用样式的1216px最大宽度限制；通用样式又将表格外边距置零，造成信息区与表格、各表格之间贴合。已在 `merchant/sales/store/detail.html` 添加仅作用于门店详情的样式：三个Tab的内容区采用18px纵向间距，直接子表格及上方信息区均占满Tab内容宽度；自营财务区末尾单独的“NC辅助核算”跨两列显示，不留半行空白。表格保留自身横向滚动，未修改共享样式或其他详情页。源码样式及HTML/JS语法静态检查通过；本轮浏览器权限仍未开放，实际像素宽度和窄屏滚动未验。
