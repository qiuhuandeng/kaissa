# 合同12301配置原型第一步实施与验收

日期：2026-09-24。依据：用户在菜单页面方案后明确“执行”。本次按方案第1步完成P01—P05及P10对应权限项；第2、3步未因此标记完成。

## 1. 业务位置与范围

本步供集团技术管理员、公司合同管理员及门店管理人员使用，承接平台开通资料、公司证照和法务确认的模板及规则，为下一步销售从订单办理合同提供可选条件。配置保存只改变当前页面演示资料，不生成正式合同、通知游客、产生收退款或完成审批。

各页面标明“配置演示、刷新恢复、未连接12301”。本页保存与复开可用于验收，不进行跨页资料自动同步。福建公司的可用授权和模板均为演示条件；北京缺资料、上海授权过期等用于演示拦截，不代表真实公司现状。

浏览器验收中发现并修正两项问题：门店旧表单按字段位置保存默认值，新增字段会造成配置值错位，现已在新字段初始化后捕获默认值；公共列表自动列宽覆盖合同列表，现由配置列表独立控制业务列及固定操作列。两项修正已纳入回归检查。

浏览器脚本使用页面DOM执行点击和填值，并结合截图检查布局；这不构成真实平台联调、真实短信或电子签章验收。角色项进行了代码及语法检查，未进行生产账号权限测试。独立公司资料编辑页的未保存退出提示已补，未单列浏览器验收场景。
