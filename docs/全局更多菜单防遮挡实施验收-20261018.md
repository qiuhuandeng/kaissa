# 全局更多菜单防遮挡实施验收

日期：2026-10-18。依据：用户明确要求“全局解决更多的下拉框被遮挡的问题”。范围是后台更多／批量操作菜单的显示和点击，不改变业务动作、权限、主流程状态或财务政策。

## 问题与处理

机位列表使用原生折叠菜单，未进入已有标准菜单处理；固定操作列各自形成层级，菜单会被后续行覆盖。原固定定位又沿用表格内部位置，横向滚动或窄屏时菜单可能出现在屏幕外。商户、管理、运营导航还存在三份不同实现，定价页另有自己的定位。

本轮统一到 `shared/action-menus.js`：商户、管理、运营、供应商四套导航自动加载；标准下拉、机位原生更多和批量操作、定价自定义更多共同处理。菜单优先进入浏览器顶层，保留原页面结构与业务事件关系；位置以触发按钮当前屏幕位置计算，左右留8px，底部空间不足时向上展开。超长菜单只在菜单内部滚动，页面仍保持表格内部横向滚动及固定操作列。点击外部、切换菜单、Escape、页面滚动和窗口变化关闭菜单；动态重绘删除来源行时清理菜单，避免残留。

## 实页验收

| 代表页面 | 核对结果 |
|---|---|
| 机位管理 | 菜单不被下行覆盖，点击按机位建团打开正确抽屉；底部不足向上展开 |
| 团期订单 | 业务、维护、危险操作菜单完整；日志仍打开当前订单的正确内容 |
| 定价策略 | 自定义更多也进入顶层，复制／线路／团期／记录／停用可见 |
| 管理后台角色 | 组织管理员的更多可见，未执行删除 |
| 运营后台组件 | Banner轮播的版本历史／停用可见，未停用组件 |
| 供应商团期 | OUT-G20260705的四项菜单可见，未改变团期 |

[页面操作记录](evidence/global-action-menus-20261018/browser-observations.json)及同目录六张截图为本轮证据。实测短窗口的CSS视口为1025×650，按钮顶部605.23px，菜单顶部466.99px、底部599.47px，正确上翻且点击命中菜单项。保留浏览器既有缩放，不修改用户浏览器缩放偏好。订单长菜单实测可视345px、内容444px，滚动至98.75px后仍保持打开。浏览器错误／警告0，新增脚本及四套导航语法通过。

共享实现覆盖四套后台导航；上述为六类真实页面抽样，不声称逐页穷举全站。旧版浏览器保留移到页面外层的降级方式，本轮验收采用支持顶层菜单的Chrome。原文件环境两项人工补验继续保留。本轮不产生新的财务批次、正式权限或财务确认规则。
